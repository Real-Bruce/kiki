# kiki Windows 首版产品规格

状态：依据用户在 2026-11-06 确认的方案和设计方向整理。未经过运行验证的性能数字均为目标，而非已实现承诺。

## 1. 产品与平台

- 名称：kiki。
- 首版：Windows 11 x64，ZIP 解压运行，不要求用户安装开发工具。
- 语言：Rust；界面语言：简体中文。
- 优先级：正确截图与编辑、启动与唤起响应、后台低占用、小体积、已批准的视觉品质。
- 默认在托盘运行，没有常驻主工作台。设置和编辑界面按需打开。
- 核心逻辑隔离平台依赖，以便以后适配 macOS；首版不实现 Mac 客户端。

## 2. 范围

必须实现：

1. 区域截图、可见顶层窗口识别/吸附、全屏截图。
2. 任意显示器和跨屏框选，混合 DPI，显示器位于主屏左侧/上方时的负坐标。
3. 矩形、箭头、画笔、文字标注；对象选择、移动、调整、删除。
4. 文字二次修改，画笔整条笔画移动/删除，撤销、重做。
5. 独立的复制、保存 PNG、置顶贴图。
6. 多张贴图并存、拖动、滚轮缩放、原比例恢复、复制、保存、关闭。
7. 托盘、热键配置、设置窗口、主题切换、可选开机启动。

后续范围，不预放空按钮：

- OCR、滚动长截图、历史记录、放大镜/取色、马赛克/模糊、录屏/GIF。
- 贴图透明度、鼠标穿透、贴图内继续编辑标注。
- 云服务、账号、AI 功能、联网同步和自动更新不属于首版任务。

## 3. 唤起与捕获

- 默认全局热键 Ctrl+Alt+A；通过系统 API 注册，不用键盘轮询或常驻键盘钩子。
- 冲突必须提示，不抢占、不静默换键。注册失败时托盘仍能开始截图。
- 托盘至少包括：开始截图、全屏截图、设置、关闭所有贴图、退出。
- 重复启动只保留一个应用实例。截图会话活动时重复热键不创建第二套遮罩。
- 唤起后先取得各屏幕快照，再显示编辑遮罩。编辑时画面冻结。
- 捕获失败恢复托盘状态，释放部分已创建资源，并显示简短错误。
- 多屏快照尽量时间接近，不承诺视频跨屏内容严格原子同步。
- 捕获期间不将本次选区遮罩和工具条包含在结果中。

## 4. 选区与多屏

- 鼠标悬停高亮可见顶层窗口，单击选中该窗口；拖动开始任意矩形框选。
- 窗口选区包含标题栏，尽量排除窗口外部阴影。
- 不识别子控件、网页 DOM；不承诺重建最小化或被遮挡窗口的隐藏内容。
- 全屏默认当前鼠标所在显示器。编辑状态中 F 可选择该屏幕；文本输入时 F 是普通字符。
- 选区具有八个调整点与物理像素尺寸标签。所有拖动方向均应有效。
- 进入选择工具后，已绘制对象的命中优先于空白区域。拖动空白区域可以移动选区。
- 调整选区时标注仍锚定在冻结图像的同一位置；成图只包含最终选区内内容。
- 保留冻结底图直到会话结束，避免缩小再放大选区导致内容丢失。
- 各屏按物理像素合成，不为统一 UI 缩放而缩放截图像素。
- 无显示器覆盖的间隙输出透明像素；处理像素步长、边界裁剪及负坐标。
- 工具条跟随选区下方/上方布局，不能越界到不可操作区域，也不能跨显示器缝隙失去可见性。
- 配置变化、拔插显示器或锁屏导致本次捕获不可继续时，安全取消会话，下一次重新枚举屏幕。

## 5. 标注对象与撤销

- 矩形：轮廓颜色、粗细、移动、尺寸调整。
- 箭头：颜色、粗细、整体移动、两端点调整。
- 画笔：一笔形成一个对象，支持整体移动/删除；不做节点级编辑。
- 文字：颜色、字号、多行、中文 IME、再次修改、位置调整。
- 顶层对象优先命中。选中显示明确的选择框或端点，不与截图边界混淆。
- 默认画线颜色为红色，粗细 3 逻辑像素，文字字号 24；各工具记住最近样式。
- 样式转换必须考虑 DPI，导出与屏幕预览视觉一致。
- 一次连续拖动/绘制视为一次撤销操作；新操作清空重做栈。
- 建议撤销最多保留 100 个编辑操作，保存参数变化/对象快照，不保存 100 份完整屏幕图像。
- 不创建截图历史库，不将标注工程持久化到磁盘。

## 6. 输出语义

复制：

- 将选区与标注合成到剪贴板，只写剪贴板，不自动创建图片文件。
- 与常见 Windows 应用的图片粘贴兼容；需要时提供 PNG 与标准位图表示。
- 成功后退出截图，失败时保留编辑会话。剪贴板短暂占用可有限重试，不能卡死 UI。

保存：

- 打开原生另存为对话框，首版输出 PNG。
- 默认文件名 kiki_YYYYMMDD_HHMMSS.png，记住最近保存目录。
- 取消保存对话框返回编辑；写入成功才结束会话。
- 同名文件交由正常覆盖确认处理，写入失败不丢失当前编辑结果。

贴图：

- 将合成图片交给独立贴图窗口，不自动写文件，不顺带覆盖剪贴板。
- 贴图成功后退出截图会话，释放未被贴图使用的资源。

共同要求：

- 所有输出包含最终标注，排除调整点、选区线、尺寸标签和工具条。
- SDR PNG 是首版统一输出。HDR 输入需正确映射为 SDR，不能直接截断高动态像素导致发灰或过曝。
- 若某个后端在特定显示模式不能保证正确输出，应转入已验证的兼容路径或清楚报错，不能默默交付错误颜色。
- 标准系统保护或不可捕获内容遵循 Windows 限制。

## 7. 快捷键与取消层级

| 场景 | 按键 | 行为 |
| --- | --- | --- |
| 全局 | Ctrl+Alt+A | 开始截图，可在设置中修改 |
| 截图编辑，非文本输入 | Enter | 复制并成功退出 |
| 截图编辑 | Ctrl+S | 保存 |
| 截图编辑 | Ctrl+P | 贴图 |
| 截图编辑，非文本输入 | Ctrl+Z / Ctrl+Y | 撤销/重做 |
| 对象选中，非文本输入 | Delete | 删除对象 |
| 截图选择/编辑，非文本输入 | F | 当前屏幕全屏选区 |
| 文本输入 | Enter / Ctrl+Enter | 换行/完成文字输入 |
| 活动操作 | Esc | 取消当前未完成拖动/输入，恢复操作前状态 |
| 无活动操作 | Esc | 取消整个截图会话 |

保存/贴图前应正确提交当前可见文字编辑。文本输入框的 Ctrl+Z、Delete 等首先作用于文本。

## 8. 置顶贴图

- 使用无普通标题栏的图片浮窗，细边框与轻阴影。
- 初始尽量 1:1 显示，大于可用屏幕时缩小适配。
- 鼠标拖动移动，滚轮以鼠标附近为中心缩放；提供恢复原始比例。
- 缩放只影响显示，不改变复制/保存的原图尺寸。
- 悬停显示复制、保存、关闭控件；右键菜单包括复制、保存、恢复原始比例、关闭。
- 多张贴图分别操作；托盘可关闭全部贴图。
- 图中的缩放比例提示是显示状态，不是图像内容。
- 关闭不自动保存，不提供退出后恢复。退出应用关闭所有贴图。
- 图片本身可以含之前的标注，但不是可再次编辑的标注工程。
- 空闲贴图按事件重绘，不持续刷新图像或轮询鼠标。

## 9. 设置与存储

- 导航：通用、快捷键、截图、贴图、外观、关于。
- 通用：开机启动默认关闭；启动驻留托盘；关闭设置窗口继续后台。
- 快捷键：修改截图热键，检测冲突，提供恢复默认。
- 截图：管理提示显示及必要的工具样式默认值，不出现后续功能入口。
- 贴图：说明操作、恢复默认显示行为；不增加未批准的穿透、透明度或恢复历史。
- 外观：跟随系统（默认）、浅色、深色，提供即时预览。
- 关于：名称、版本、简要操作帮助和第三方许可信息。
- 设置自动保存，采用有版本号的本地配置文件，安全写入，损坏时恢复默认并提示。
- 配置位于当前用户 LocalAppData/kiki，程序目录可以只读。
- ZIP 是免安装分发，并不表示配置随 EXE 携带。首版不另做目录内配置模式。
- 开机启动仅经用户在应用内开启后配置；应用位置改变时可在设置中修复。
- 日志只记录有限诊断信息并有容量上限，不记录截图像素、剪贴板内容或输入文字。

## 10. 性能与验收

| 项目 | 目标 |
| --- | --- |
| 应用运行文件合计 | 解压后 ≤10 MiB，不含调试符号、文档和设计参考 |
| 完全闲置后台 | 无会话、无贴图、无设置窗口，私有工作集目标 ≤20 MiB |
| 闲置 CPU | 60 秒平均 ≤0.1%，按整机处理器总量归一化 |
| 启动到热键可用 | P95 ≤500 ms |
| 第一次截图唤起 | 热键到冻结画面可框选，P95 ≤500 ms |
| 后续截图唤起 | 同一进程，P95 ≤200 ms |
| 生命周期 | 连续使用后回到稳定资源水平，无随次数持续增长 |

要求：

- 这些数字需要 Release 构建和明确测试机。记录 CPU、RAM、GPU、Windows build、显示器分辨率、缩放、HDR、刷新率。
- 至少 30 个有效时延样本，分别报告进程冷启动、首次截图、后续截图；不能把预热样本混入冷启动。
- 多显示器和单显示器结果分别报告，不保证所有硬件达到同一值。
- 同时记录 private working set、private bytes、GPU 内存、GDI/USER 句柄变化。
- 不通过清空工作集、删除统计或只采样最低值“达标”。
- 编辑和贴图内存按实际图像测量，不套用 20 MiB。4K RGBA8 单份底图约 31.6 MiB。
- 系统剪贴板占用与本应用占用分开说明；避免同时长期保留冗余 CPU/GPU 副本。
- 性能不达标应报告原因、优化结果和剩余差距，不静默修改目标。

至少覆盖：单屏；100%/150%/200% 混合双屏；副屏在左/上；竖屏；跨屏边缘与缝隙；中文输入；标注修改/撤销；剪贴板占用；保存取消/失败；多张贴图；热键冲突；反复截图/取消/关闭；深浅色；HDR 转 SDR。
