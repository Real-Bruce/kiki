# 使用说明

## 启动与设置

下载并解压 ZIP 后运行 kiki.exe。首次启动显示通用页；以后驻留托盘。关闭设置窗口不会退出应用，退出请使用托盘菜单。默认 Ctrl+Alt+A 开始截图，冲突时从托盘进入设置修改组合键。

设置自动保存到当前用户 LocalAppData/kiki。开机启动默认关闭，只有手动开启才生效。程序移动位置后可在设置中修复启动项。

## 截图与标注

拖动框选；单击高亮窗口选中可见窗口范围。拖动选区内部移动，八个调整点改变尺寸。F 选择鼠标所在屏幕，文字输入时 F 为普通字符。

工具顺序为选择、矩形、箭头、画笔、文字、撤销、重做、贴图、保存、复制、取消。选择已有对象后可移动或删除；矩形可调整尺寸，箭头可拖动端点。切到相应工具修改样式。文字双击重编，拖动顶部圆点旋转。

| 场景 | 快捷键 | 操作 |
| --- | --- | --- |
| 截图，非文字输入 | Enter | 复制 |
| 截图 | Ctrl+S / Ctrl+P | 保存 PNG / 贴图 |
| 标注 | Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 选中对象 | Delete | 删除 |
| 文字输入 | Enter / Ctrl+Enter | 换行 / 提交 |
| 活动操作 | Esc | 取消当前操作；无活动操作时取消截图 |

取消保存或输出失败会保留编辑。复制与贴图不自动写文件，保存使用原生对话框。输出不包含工具条、选区线与调整点。

## 置顶贴图

拖动移动、滚轮缩放、Ctrl+0 恢复原比例、Ctrl+C 复制、Ctrl+S 保存、Esc 关闭。悬停和右键菜单也提供操作。缩放只改变显示，复制与保存维持原图尺寸。托盘「关闭贴图」关闭所有贴图。

## 主题与限制

外观支持跟随系统、浅色、深色。首版不包含 OCR、长截图、马赛克、录屏、历史、取色或贴图再次标注。更多环境限制见 [当前进度](PROGRESS.md)，包内简明说明见 [QUICK_START.txt](QUICK_START.txt)。
