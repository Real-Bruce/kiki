# 使用说明

## 启动与设置

下载并解压 ZIP 后运行 kiki.exe。首次启动显示通用页；以后驻留托盘。关闭设置窗口不会退出应用，退出请使用托盘菜单。默认 Ctrl+Alt+A 开始截图，冲突时从托盘进入设置修改组合键。

设置自动保存到当前用户 LocalAppData/kiki。开机启动默认关闭，只有手动开启才生效。程序移动位置后可在设置中修复启动项。

## 截图与标注

拖动框选，或单击高亮窗口选中可见窗口范围。拖动选区四边或八个调整点即可改变截图范围。未使用绘图工具时，可从选区内的空白处拖动选区；使用绘图工具时，按住空格再拖动。F 选择鼠标所在屏幕，文字输入时 F 为普通字符。

用对应工具拖矩形轮廓、箭头主体或画笔笔迹，即可移动已有标注。拖已选矩形的控制点调整大小，拖箭头任一端点改变长度和方向。用文字工具单击内容重新编辑，拖边框移动，拖顶部圆点旋转。输入文字后可直接拖圆点，应用会提交当前文字并开始旋转。旋转过的文字在编辑时水平显示，提交后恢复角度。

再次点击已激活的绘图工具可回到选择状态。此时可移动选区或选中已有标注，文字工具开启时可双击已有文字重编。

在 v0.4.0 中，矩形、箭头、画笔分别记忆线宽。在线宽滑杆拖动，或在数值框输入 1–64 后按 Enter，也可以在截图画布上滚动鼠标，每格调 1 px。线宽按成图像素计算。调节会更新当前选中或正在绘制的标注，并把数值保存为该工具的默认线宽。可在「设置 → 截图」查看或更改三个默认值。撤销只恢复标注本身的线宽。

在 v0.5.0 中，文字工具使用同一滑杆、数值框和滚轮操作。字号支持 8–256 px，默认 24 px，每格滚轮调 1 px。调节会更新当前文字或草稿，并把数值保存到「设置 → 截图」。输入法正在选词时，仍可用滚轮或滑杆，文字会在选词结束后重排。确认候选后可在数值框输入精确字号。

| 场景 | 快捷键 | 操作 |
| --- | --- | --- |
| 截图，非文字输入 | Enter | 复制 |
| 截图 | Ctrl+S / Ctrl+P | 保存 / 贴图 |
| 标注 | Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 选中对象 | Delete | 删除 |
| 文字输入 | Enter / Ctrl+Enter | 换行 / 提交 |
| 活动操作 | Esc | 取消当前操作；无活动操作时取消截图 |

取消保存或输出失败会保留编辑。复制与贴图不自动写文件，保存使用原生对话框。输出不包含工具条、选区线与调整点。

普通截图和长图编辑可点击双页图标复制，或按 Enter。撤销和重做通过 Ctrl+Z / Ctrl+Y 操作。按 Tab 或 Shift+Tab 可在工具条按钮间切换焦点。

从 v0.6.1 起，可在「设置 → 截图 → 图像输出」拖动滑杆或输入 0–256 px 设置圆角半径，默认 0 px。新截图的预览和成图使用同一个半径上限，即选区短边的一半。圆角同时裁切画面和标注，PNG 及支持透明度的剪贴板格式保留透明角，贴图沿用同一成图。

在 v0.7.0 中，截图和贴图的另存为窗口均支持 PNG 和 JPEG。「设置 → 截图 → 图像输出」中的格式决定每次打开对话框时的默认选项。对话框可单独切换本次格式。PNG 保存为 `.png` 并保留透明像素。JPEG 保存为 `.jpeg`，透明部分合成到白底，品质为 90%。

在「设置 → 截图 → 工具显示」可按图标分别开启或关闭矩形、箭头、画笔、文字、马赛克、编号、长截图和取色。下方预览即时显示开关变化。关闭工具后工具条会收拢空位，已有标注与工具参数会保留。贴图、保存、复制和取消始终可用，窄屏上可从「更多」选用收纳的工具。

马赛克默认关闭。开启后，可在「设置 → 截图 → 默认标注样式」调整默认颗粒。在截图工具条选择马赛克并拖出矩形。拖矩形内部可移动，拖八个控制点可调整覆盖范围。用滚轮每格调节 1 px，也可通过滑杆或数值框设置 2–64 px 颗粒大小。调节值同步为下次默认值。马赛克覆盖冻结画面，其他标注显示在它上方。

编号默认关闭。开启后选择编号工具，点击选区内空白位置插入，拖动已有编号可移动。选中编号后按 Delete 删除，后续编号自动前移。Ctrl+Z / Ctrl+Y 可撤销或重做。每次新截图从 1 开始。用滚轮每格调直径 2 px，也可通过滑杆或数值框设置 16–128 px。截图内调整会同步为下次默认值。

取色默认关闭。开启后选择取色工具，在选区内移动指针可查看冻结底图的颜色和 HEX 编码。按一次 Shift 切换到 RGB，松开后保持，再按一次切回 HEX。点击可复制当前编码，继续在同一张截图内取色。透明间隙会显示「无像素」。

在「设置 → 截图」底部选择「恢复默认」并确认。截图提示与原有四个绘图工具会开启，马赛克、编号、长截图和取色关闭，颗粒和编号直径分别恢复到 12 px 和 28 px。默认颜色恢复为红色，矩形、箭头和画笔线宽各为 3 px，字号为 24 px，圆角为 0 px，输出格式为 PNG。快捷键、主题、自启、保存目录、首次提示记录和当前截图的标注与文字草稿均保留。若页脚提示保存失败，可选择「重试保存」。

## 长截图

1. 在「设置 → 截图 → 工具显示」开启「长截图」。开始截图后，在同一块屏幕内框选可滚动正文，避开固定页头、底栏和悬浮内容。
2. 点击工具条的「长截图」。此时会清空本次普通截图中的标注、文字草稿和撤销历史。首帧出现后，把指针放回正文，缓慢向下滚动，右侧预览显示已拼接的内容。
3. 接缝无法匹配时，缓慢滚回已捕获的位置，或者点「完成」保留已拼接部分。长图最多 32768 px 高，原始像素最多 256 MiB，先达到的上限生效。按 Esc 或点「取消」结束本次截图。
4. 点「完成」后，从顶部进入长图编辑。用右侧缩略图或滚动条浏览，主画布上的滚轮继续调节当前工具参数。可以标注或取色，也可以复制、保存或贴图，输出覆盖完整长图。

## 置顶贴图

拖动移动、滚轮缩放、Ctrl+0 恢复原比例、Ctrl+C 复制、Ctrl+S 保存、Esc 关闭。悬停和右键菜单也提供操作。缩放只改变显示，复制与保存维持原图尺寸。托盘「关闭贴图」关闭所有贴图。
