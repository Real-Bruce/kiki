# 版本变更

## 2.0.4（候选）

- 圆角预览与滑杆区域各占一行的 50%；预览占左侧区域宽度的 60%，水平和垂直居中。
- 棋盘格增大至 12 DIP，并在色块周围保留背景边距，PNG／JPEG、零圆角与非零圆角均能看到棋盘格。
- 自动检查与打包通过，按用户要求由用户进行真机界面复测。见[比例与背景修订](validation/settings/corner-balanced-v2.0.4.md)。

## 2.0.3（候选）

- 移除截图页「用于新标注」说明、可见的「圆角半径」标签及圆角预览旁两句说明。
- 圆角预览与滑杆改为同一行，预览在左，滑杆紧随右侧并垂直居中，像素读数仍在最右侧。
- 修复所有设置滑杆在最小／最大值时圆环被裁切，绘制与指针调节共用带安全边距的端点。验证见[滑杆及圆角排版](validation/settings/slider-corner-v2.0.3.md)。

## 2.0.2（候选）

- 截图设置首组改名「工具条」，展开的工具选项改为单行图标、名称及右侧开关，与通用页开关样式一致。
- 移除样式参数和圆角的范围描述，保留当前像素读数；圆角为零时仅显示「无」。
- 验证与实拍见[截图设置修订](validation/settings/capture-refinement-v2.0.2.md)。

## 2.0.1（候选）

- 快捷键导航按用户提供的键盘 SVG 调整，截图导航恢复交叉裁切线，两者沿用统一圆端描边。
- 通用页移除整个「开始截图」分组及指定托盘提示，只保留「启动与后台」「设置文件」。应用移动后的提示和更新按钮独立排列，与自启开关以分隔线和留白区分。
- 截图入口说明同步改为热键或托盘；验证见 [通用页与导航修订](validation/settings/settings-refinement-v2.0.1.md)。

## 2.0.0（候选）

- 按已确认的 B 版排版升级六页设置，以暖灰底面、圆角分组和统一标题层级组织内容。
- 截图、工具预览、工具开关及贴图共享 A 版圆角细线图标；马赛克采用规整双色像素格，长截图采用双向下折线。
- 统一导航图标、松绿选中色环、滑杆圆点及主题卡片反馈。保留原有工具顺序、默认开关、参数与快捷键行为。
- 候选包及实际验证范围见 [界面升级验证](validation/settings/ui-upgrade-v2.0.0.md)，完整 DPI／实机矩阵仍待补验。

## 1.0.24

- 长截图采集中，在选区内滚动时，框内正文和框外可见的同一页面同步滚动。原选区保持清晰，框外以半透明遮罩压暗。

## 1.0.23

- 长截图支持用同一滚动正文的更高区域帮助对齐。按住 Shift 点击「长截图」，再框选包含原选区的正文。预览和成图取原选区扫过的内容。

## 1.0.22

- 修复长截图中纯色重叠干扰有效接缝的问题。逐像素精确匹配时，少量清晰的横向边界也可支撑唯一接缝。

## 1.0.17

- 便携 ZIP 内仅包含 `kiki.exe`、`README.txt` 和合并项目、第三方依赖及 Rust 标准库许可的 `LICENSE.txt`。

## 1.0.16

- 统一「关于」页的帮助段落间距，按实际换行排版。

## 1.0.15

- 「关于」页直接显示版本与分组使用帮助。第三方许可原文随 ZIP 提供。
- 「打开设置文件夹」移至「通用」页的「设置文件」分组。

## 1.0.14

- 「设置 → 截图」的默认标注样式和圆角改用滑杆调节，右侧显示当前像素值。将指针移到滑杆上可用滚轮微调。

## 1.0.13

- 修复从「通用」页点击「开始截图」时，设置窗口的退出动画被截入图片的问题。

## 1.0.12

- Windows 平台代码按应用、采集、编辑、贴图、设置、输出及共享能力分目录，测试和开发文档同步整理。
- 本次为内部结构维护，截图、标注与贴图行为沿用 1.0.11。

## 1.0.11

- 贴图右键菜单采用与托盘菜单一致的浅深配色、圆角、分隔线和选中效果，快捷键在右侧对齐。
- 贴图右上角的复制、保存、关闭换成同一套线性图标，统一线宽与命中区。按钮有悬停和按下反馈。

## 1.0.10

- 项目采用 MIT 开源协议，Windows 便携 ZIP 同时提供项目协议和第三方许可。
- 更新中英文项目介绍与六张真实界面截图，按功能模块整理设计、开发及验证文档。
- 完成开源前信息检查，排除本地 IDE 配置；本版本的截图与标注功能沿用 1.0.9。

## 1.0.9

- 「通用」页在开始截图入口下说明如何框选、复制粘贴、保存和贴图。
- 「截图」页先显示工具开关和实时预览，数值范围与对应参数一起显示，保存格式与圆角示意集中在同一组。恢复截图默认设置移至页尾。
- 统一六页的标题、分隔线、按钮和提示文案，并提高滑杆轨道的对比度。

## 1.0.8

- 修复浅色和深色「截图」设置页拖动线宽、字号等滑块时的闪烁。滑块、数值框和圆角预览随操作同步更新。

## 1.0.7

- 修复浅色和深色设置页在滚动时闪烁、控件消失及错位的问题。页面无法继续滚动时保持当前画面。

## 1.0.6

- 修复快速滚动设置时，滑杆和按钮短暂闪成白块的问题。

## 1.0.5

- 「快捷键」页集中显示贴图的恢复原始比例、复制、保存和关闭快捷键。
- 「截图」页的「恢复默认」移到「截图提示」上方。

## 1.0.4

- 长截图预览优先放在选区外。Windows 屏幕共享可以显示遮罩、预览和操作按钮，长图采集仍只读取选区内的内容。

## 1.0.3

- 修复进入长截图时选区和滚轮路由异常。滚轮短暂经过浮层后，回到正文可继续拼接。
- 首帧失败时可直接拖动重选区域。重选期间避免单击吸附到最大化窗口。

## 1.0.2

- 精简普通截图和长图编辑工具条，保留绘图箭头和撤销按钮，重做通过 Ctrl+Y 操作。
- 复制改为线性图标，按下时沿用悬停样式，保留键盘焦点和 Enter 快捷键。
- 截图设置的工具条预览同步精简，关闭工具后相邻按钮和分组自动收拢。

## 1.0.1

- 统一应用版本来源。「关于」页、Windows EXE 和便携 ZIP 使用同一个版本号。
- GitHub Release 自动采用版本标签里的更新介绍，并附带 Windows x64 便携包和 SHA-256 校验文件。

## 1.0.0

- 新增单屏纵向手动长截图，右侧显示实时拼接预览。长截图默认关闭，可在截图设置中开启。
- 完成采集后可从右侧缩略图浏览长图，继续标注或取色，并将完整长图复制、保存或贴图。
- 修复采集时选区外围遮罩消失，以及滚动条变化或小范围重绘造成的长图拼接失败。
- 长截图在连续滚动时逐帧尝试拼接，滚动停下后再确认是否缺少可对齐的接缝。

## 0.11.0

- 截图可对选区内的冻结底图取色，实时显示色块和 HEX 或 RGB 编码。
- 取色默认关闭。开启后每次进入从 HEX 开始，按一次 Shift 切换格式。单击复制颜色编码后可继续取色。

## 0.10.0

- 截图可插入、拖动红色圆环编号。删除后连续重排，撤销或重做同步恢复顺序。
- 编号默认关闭。开启后可用滚轮、滑杆或数值框调直径，范围 16–128 px，默认 28 px，调节值同步到截图设置。

## 0.9.0

- 截图工具条新增可编辑马赛克，可拖动覆盖区域和八个控制点。滚轮、滑杆和数值框可调颗粒大小，范围 2–64 px。
- 马赛克默认关闭。开启后在截图设置的「默认标注样式」末尾设置默认颗粒，并在「工具显示」下方预览工具条。恢复截图默认设置时关闭并恢复 12 px。
- 马赛克应用于冻结底图，普通标注绘制在上层。复制、保存和贴图沿用相同的像素化结果。

## 0.8.1

- 移除截图工具条左侧的选择箭头。再次点击已选绘图工具可回到选择状态。
- 截图设置使用与工具条同序、同图标的开关，并实时预览工具条。

## 0.8.0

- 截图设置页可独立开启或关闭矩形、箭头、画笔和文字。默认四项开启，关闭后保留参数和已有标注。
- 工具条随开关收拢空位，键盘焦点跟随可见项。窄屏可用「更多」访问收纳的工具，输出和取消固定可达。

## 0.7.1

- 截图设置页可在确认后恢复截图提示、标注样式、圆角和输出格式的默认值。快捷键、主题、自启、保存目录和当前编辑内容保留。

## 0.7.0

- 截图和贴图支持另存为 PNG 或 JPEG，默认格式可在截图设置中调整。
- JPEG 使用白底和 90% 品质。PNG 保留圆角与屏幕间隙的透明度。
- 取消保存或保存失败后可继续编辑文字草稿。

## 0.6.1

- 修复首次进入截图设置页时，滚动条使数值框偏移并遮挡边框与 px 单位的问题。

- 「设置 → 截图 → 图像输出」增加圆角半径和透明角示意，支持 0–256 px，默认 0 px。
- 截图预览与成图使用实际选区尺寸限制半径。保存、复制和贴图共用裁切后的画面与标注，PNG 保留平滑的透明角。

## 0.5.0

- 文字字号支持 8–256 个成图像素。截图工具和设置页提供滑杆与数值输入，截图内也可用滚轮每格调 1 px。
- 字号调整会保存为文字工具默认值。连续滚轮调整已提交的文字可一次撤销，旋转文字重排时保留角度与中心。
- 矩形、箭头、画笔各自记忆 1–64 px 线宽。旧版共享线宽迁移为三个工具的默认值。

## 0.4.0 候选

- 矩形、箭头、画笔独立记忆 1–64 px 线宽。支持滑杆、数值输入和截图画布滚轮，默认值与设置同步。
- 线宽以实际成图像素为单位。升级时将旧版共享线宽迁移为三个工具的默认值。

## 0.3.0

- 矩形、箭头、画笔和文字可使用对应工具直接编辑，支持调整矩形和箭头、重编及旋转文字。
- 截图选区四边和八个控制点可直接拖动。使用绘图工具时，可按住空格拖动选区。

## 0.2.2

- 更新应用图标的松绿底色与暖白猫爪，改善边缘过渡。

## 0.2.1

- 按 01-capture.png 对齐截图工具条的图标轮廓、尺寸、间距及分隔线，移除底部硬阴影。
- 箭头采用实心尖端，画笔使用连续圆角路径。两者取消矩形线框。
- 透明文字框随内容伸缩，文字可移动、自由旋转、重编与撤销。
- 重排六个设置页，增加模块间留白和分割线，使用色点、线宽示例与主题预览。设置侧栏沿用软件图标。

- 设置窗口的开关、色点、按钮与焦点边框采用平滑边缘绘制。标题栏左侧留空，右侧保留系统窗口按钮。快捷键设置通过文字提示录入组合键。

- 托盘右键菜单精简为四项，宽度随文字计算，采用浅分隔线和圆角。移除右侧及底部的硬阴影。

- 首次启动提供“开始截图”入口。设置和托盘菜单统一暖灰与松绿，按当前操作显示必要提示。

- 截图选区、工具条、参数面板与应用爪印图标统一松绿主题。

## 0.1.0

- 新增 Windows 11 x64 免安装截图工具，支持默认全局热键 Ctrl+Alt+A、托盘和设置。
- 支持区域、窗口吸附和全屏选区，提供矩形、箭头、画笔、文字及可编辑标注和撤销重做。
- 支持剪贴板图像、PNG 保存和多张置顶贴图，取消保存或输出失败时保留编辑。
- 支持系统、浅色和深色主题，自定义热键、默认标注样式、保存偏好与显式开机启动。
- 复用捕获线程，空闲时释放绘图设备。HDR 映射、混合 DPI 实机验证及 200% 下的时延差距见 [P8 交付报告](validation/engineering/P8.md)。
