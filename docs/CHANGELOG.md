# 版本变更

## 0.10.0 候选

- 截图可插入、拖动红色圆环编号。删除后连续重排，撤销或重做同步恢复顺序。
- 编号默认关闭。开启后可用滚轮、滑杆或数值框调直径，范围 16–128 px，默认 28 px，调节值同步到截图设置。

## 0.9.0

- 截图工具条新增可编辑马赛克，可拖动覆盖区域和八个控制点。滚轮、滑杆和数值框可调颗粒大小，范围 2–64 px。
- 马赛克默认关闭。开启后在截图设置的「默认标注样式」末尾设置默认颗粒，并在「工具显示」下方预览工具条。恢复截图默认设置时关闭并恢复 12 px。
- 马赛克应用于冻结底图，普通标注绘制在上层。复制、保存和贴图沿用相同的像素化结果。

## 0.8.1

- 移除截图工具条左侧的选择箭头。再次点击已选绘图工具可回到选择状态。
- 截图设置使用与工具条同序、同图标的开关，并实时预览工具条。

## 0.8.0

- 截图设置页可独立开启或关闭矩形、箭头、画笔和文字。默认四项开启，关闭后保留参数和已有标注。
- 工具条随开关收拢空位，键盘焦点跟随可见项。窄屏可用「更多」访问收纳的工具，输出和取消固定可达。

## 0.7.1

- 截图设置页可在确认后恢复截图提示、标注样式、圆角和输出格式的默认值。快捷键、主题、自启、保存目录和当前编辑内容保留。

## 0.7.0

- 截图和贴图支持另存为 PNG 或 JPEG，默认格式可在截图设置中调整。
- JPEG 使用白底和 90% 品质。PNG 保留圆角与屏幕间隙的透明度。
- 取消保存或保存失败后可继续编辑文字草稿。

## 0.6.1

- 修复首次进入截图设置页时，滚动条使数值框偏移并遮挡边框与 px 单位的问题。

- 「设置 → 截图 → 图像输出」增加圆角半径和透明角示意，支持 0–256 px，默认 0 px。
- 截图预览与成图使用实际选区尺寸限制半径。保存、复制和贴图共用裁切后的画面与标注，PNG 保留平滑的透明角。

## 0.5.0

- 文字字号支持 8–256 个成图像素。截图工具和设置页提供滑杆与数值输入，截图内也可用滚轮每格调 1 px。
- 字号调整会保存为文字工具默认值。连续滚轮调整已提交的文字可一次撤销，旋转文字重排时保留角度与中心。
- 矩形、箭头、画笔各自记忆 1–64 px 线宽。旧版共享线宽迁移为三个工具的默认值。

## 0.4.0 候选

- 矩形、箭头、画笔独立记忆 1–64 px 线宽。支持滑杆、数值输入和截图画布滚轮，默认值与设置同步。
- 线宽以实际成图像素为单位。升级时将旧版共享线宽迁移为三个工具的默认值。

## 0.3.0

- 矩形、箭头、画笔和文字可使用对应工具直接编辑，支持调整矩形和箭头、重编及旋转文字。
- 截图选区四边和八个控制点可直接拖动。使用绘图工具时，可按住空格拖动选区。

## 0.2.2

- 更新应用图标的松绿底色与暖白猫爪，改善边缘过渡。

## 0.2.1

- 按 01-capture.png 对齐截图工具条的图标轮廓、尺寸、间距及分隔线，移除底部硬阴影。
- 箭头采用实心尖端，画笔使用连续圆角路径。两者取消矩形线框。
- 透明文字框随内容伸缩，文字可移动、自由旋转、重编与撤销。
- 重排六个设置页，增加模块间留白和分割线，使用色点、线宽示例与主题预览。设置侧栏沿用软件图标。

- 设置窗口的开关、色点、按钮与焦点边框采用平滑边缘绘制。标题栏左侧留空，右侧保留系统窗口按钮。快捷键设置通过文字提示录入组合键。

- 托盘右键菜单精简为四项，宽度随文字计算，采用浅分隔线和圆角。移除右侧及底部的硬阴影。

- 首次启动提供“开始截图”入口。设置和托盘菜单统一暖灰与松绿，按当前操作显示必要提示。

- 截图选区、工具条、参数面板与应用爪印图标统一松绿主题。

## 0.1.0

- 新增 Windows 11 x64 免安装截图工具，支持默认全局热键 Ctrl+Alt+A、托盘和设置。
- 支持区域、窗口吸附和全屏选区，提供矩形、箭头、画笔、文字及可编辑标注和撤销重做。
- 支持剪贴板图像、PNG 保存和多张置顶贴图，取消保存或输出失败时保留编辑。
- 支持系统、浅色和深色主题，自定义热键、默认标注样式、保存偏好与显式开机启动。
- 复用捕获线程，空闲时释放绘图设备。HDR 映射、混合 DPI 实机验证及 200% 下的时延差距见 [P8 交付报告](validation/P8.md)。
