## 图像生成提示

使用内置 imagegen。共同提示为平面高保真 Windows 11 界面，使用现有 kiki 爪印标识、六项简体中文导航、松绿强调色、浅深成对预览和统一的线性图标。设置页展示工具条、样式及保存三组内容，编辑器展示默认工具组合及红色箭头。分别附加「近白平面与组间留白」「浅雾绿底与三块细边面板」「同色底面与对齐细线」三种表现要求。

已目视核对三张图的主要标签、控件和浅深主题。当前处于设计方向评审。图中滑杆位置、工具组的分隔线和示例底图仅用于表现视觉，后续实现以真实数值和[视觉规范](../../DESIGN_SPEC.md)为准。深浅主题切换时，框选内继续显示捕获内容的原色。完整参数及交互见[视觉规范](../../DESIGN_SPEC.md)和[功能草图](../next/README.md)。
