## P1 本轮记录

- 新增 Cargo 工程、锁定工具链与依赖、GUI subsystem/PMv2 manifest、单实例/托盘/系统热键。
- 核心物理矩形与自有 BGRA 像素、透明间隙合成；平台模块负责 WGC/D3D11、WIC、Direct2D/DirectWrite 和原生 EDIT。
- 工作者只在会话内捕获，失败受控返回托盘；加入显式开发探针用于复测。
- 修复旧 HWND、后台启动窗口不可见、COM 工厂生命周期及 IntelControlLib.dll 卸载崩溃；两轮各 100 次捕获退出码 0。
- fmt、严格 Clippy、3 项测试和 Release 构建通过；PNG 尺寸/颜色/透明像素往返通过。
- 100 样本 WGC P95 为 60.273 ms；一次 79.129 秒托盘闲置私有工作集约 4.02 MiB，CPU 增量低于计数器分辨率。不是完整产品达标结论。
- 关联提交主题：feat(app): establish native Rust tray and capture foundation。
- 遗留：见 validation/P1.md。不重复建立工程，也不将 P2–P8 标为完成。
