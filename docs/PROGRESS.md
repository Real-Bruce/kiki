3. 补齐不同环境下的中文 IME 和重编取消矩阵，以及系统主题广播和登录自启验证。
4. 复核 200% 后续截图时延波动；性能口径与未达标样本保留在 P7。
5. 在独立无开发工具的 Windows 11 x64 系统验收 ZIP。标签发布工作流已配置，云端执行与上传仍待真实发布验证。
