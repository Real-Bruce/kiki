# kiki 视觉与交互基线

用户已批准本目录设计参考所展示的方向。实现必须保持这一套视觉语言，不能另起一套未经批准的 UI。

2026-11-10 已确认 F01–F12 功能方案。新版草图提供可编辑的视觉说明，实际生效版本见当前进度。 [功能方案](FEATURE_PLAN.md) · [设计草图](design/next/README.md) · [当前进度](PROGRESS.md)

## 2. 设计语言

- Windows 11 风格：圆角、柔和阴影、细边框、适度半透明。
- 设置、托盘和截图共用松绿强调色。浅色为 #365F56，深色为 #A0CEBB。强调用于当前工具、选区、焦点和主操作。
- 标注默认红色，其他预设颜色按标注内容选择。
- 浅色与深色均采用暖灰基调，浮动工具条保留细边框。
- 使用一致的单线图标，避免 Emoji、混合图标风格和依赖远程图标。
- 字体采用系统 UI 字体及中文回退；优先清晰可读，不随应用捆绑大型字体包。
- 透明效果只用于必要面板，保持文字对比。系统关闭透明效果或合成能力不足时可使用同色实色降级。
- 使用公开、受支持的系统能力；不依赖未文档化 API 制作模糊特效。
- 不使用连续装饰动画，界面静止时不持续消耗绘制资源。

## 3. 初始逻辑尺寸

以下为实现起点，以逻辑单位随 DPI 缩放，不照抄图片像素尺寸：

| 项目 | 建议 |
| --- | --- |
| 主工具条高度 | 48 DIP |
| 普通按钮命中区域 | 至少 36 × 36 DIP |
| 截图主条图标 | 以 01-capture.png 的轮廓为准，最长边约 18 DIP |
| 截图主工具条圆角 | 10 DIP |
| 普通按钮圆角 | 6 DIP |
| 参数面板圆角 | 10–12 DIP |
| 选区到工具条间距 | 8–12 DIP |
| 主工具条到参数条 | 6–8 DIP |
| 设置窗口初始尺寸 | 约 960 × 680 DIP，受当前工作区限制 |
| 设置侧栏 | 约 180–200 DIP |
| 设置内容边距 | 24 DIP |

不得为遵守某个尺寸而让按钮越界、文字被截断或工具条无处显示。小工作区可滚动设置内容。

## 4. 截图界面

参考 01-capture.png。

- 选区之外使用中性灰遮罩，选区内维持截图原色。
- 箭头从按下点拉向实心尖端。箭头与画笔无矩形外框，选中后分别显示端点和沿笔迹的高亮。
- 文字输入框无底色，细边框随文字宽度和行高变化。F01 起文字工具单击内部直接重编，边框拖动移动，顶部圆点旋转；重编时文字暂时水平，提交后恢复角度，文字选取和中文输入优先。
- 松绿色细选区线带中性衬边，八个调整点用主题底色填充。标注对象调整点用实心强调色区分。
- 尺寸标签用实际成图物理像素，不显示逻辑尺寸冒充像素。
- 工具条在选区下方居中；不够则上方；再不足则收纳到可用屏幕内，并保证点击可达。
- 跨屏时将整个工具条放在合适的一块屏幕上，不能停在显示器间隙中。
- 主工具条、参数条、提示都不能进入最终合成图片。
- 屏幕左下可显示轻量快捷键提示，熟悉后可在设置中关闭。
- F01 起当前工具直接命中同类型对象；矩形内部空白可继续绘制嵌套矩形，箭头线身可移动、两端可调整。输入优先级：工具控件 → 文字编辑/已开始拖动 → 截图整边及八点 → 已选对象控制点 → 同类对象轮廓/笔迹 → 空白新建；重合时也遵循此顺序。
- F04 起选区圆角随设置预览，控制点仍按外接矩形布置；最终底图和标注一起裁角。PNG 透明角与 JPEG 白底角应有明确预览，不能只将选区描边画圆。

## 5. 工具条与参数条

截图主工具条的比例、留白和图标轮廓以 01-capture.png 为准。参数状态参考 02-toolbars.png，颜色使用共用暖灰与松绿。

v0.2.2 至 v0.8.0 工具条顺序：

选择、矩形、箭头、画笔、文字 | 撤销、重做 | 贴图、保存、复制 | 取消

- F07 起工具开关控制已有绘图工具；新工具在对应功能阶段完成时才加入工具条和设置。F12 最终全开顺序：矩形、箭头、画笔、文字、马赛克、编号 | 长截图、取色、撤销 | 贴图、保存、复制 | 取消。
- 原四工具默认开启，新四工具默认关闭；隐藏后不留空位或冗余分隔线。输出和取消固定可达，极窄工作区把绘图工具收进“更多”，不缩小到无法点击。
- F07 人工复测优化后移除鼠标选择按钮。F12 保留撤销按钮和 Ctrl+Z，重做通过 Ctrl+Y 操作。复制使用线性图标，保留悬停、焦点和结果反馈，按下时沿用悬停样式。
- 主条归一到 48 DIP 高，普通按钮中心间距约 46 DIP、命中区为 42×36 DIP。分隔线随实际组动态生成，主条保留细边框，无底部硬阴影。
- 当前工具与参数使用松绿圆角高亮。悬停、按下、禁用和键盘焦点分别呈现。
- 撤销按钮常驻，无可撤销操作时显示为禁用。设置预览以禁用状态展示撤销；窄屏将绘图与采集工具收纳至「更多」时，撤销仍留在工具条。
- 悬停显示名称与已实现的快捷键，不显示未实现的按键说明。
- 参数条根据工具出现。选择工具可不显示绘图参数。
- F02/F03 参数使用预设颜色、连续滑杆和数值输入，单位是成图实际 px；普通滚轮每格调整 1 px。马赛克参数为颗粒大小，编号参数为直径（每格 2 px）。范围和默认值统一取 FEATURE_PLAN.md。
- 预设颜色建议红、橙、黄、绿、蓝、紫、白、黑。黑白在不同主题下有可见边框。
- 每个工具的参数变化即时预览，统一与导出结果匹配。
- 工具条两种主题必须都实现。不要只做深色再反转颜色。

## 6. 设置窗口

以 [新版设置效果图](design/05-settings-layout.png) 为视觉参考。03-settings.png 保留为早期稿。

- 设置标题栏左侧留空，右侧保留 Windows 的最小化、最大化和关闭按钮。侧栏品牌标识与程序和托盘共用内嵌应用图标。导航图标采用同一套线性样式。
- 设置和托盘菜单使用暖灰背景和松绿强调色。设置字号为 24、16、14 和 12 DIP。右侧用标题、对齐和留白组织内容，只在大的功能模块之间使用细分割线。
- 通用页先显示「开始截图」和已注册的快捷键，紧接框选、复制粘贴、保存和贴图提示。开机启动和后台入口说明单独分组。普通行高 42 DIP，内容超出窗口时可滚动。
- 截图页依次展示截图工具条、默认标注样式、保存与圆角。工具开关按截图工具条顺序排列，每项包含同款线性图标、名称与开关，窄窗按原顺序折行。开关下方即时预览可见工具，并可调整操作提示。外观页用三张等宽主题缩略图，选中标签显示松绿色勾选标记。
- 保留通用、快捷键、截图、贴图、外观、关于六个页面及现有设置动作。F05 后格式控件可选择 PNG/JPEG，圆角附效果预览；原“固定 PNG”说明同步更新。快捷键录入与冲突处理保持。
- 固定贴图快捷键放在「快捷键」页的独立分组。「恢复截图默认设置」放在截图页底部，使用范围明确的确认框。
- 新增工具默认关闭，开启后展开对应参数。每项数值显示像素单位和有效范围。马赛克颗粒和编号直径位于「默认标注样式」末尾。恢复截图默认设置时保留热键、主题、开机启动、保存位置及当前标注和文字草稿。底部保存状态固定，长内容可滚动。
- 键盘焦点有独立提示，Tab 可滚动到屏外控件。保存状态区固定在底部，分别显示待更改、保存中、成功或失败；失败提供重试。
- 托盘右键菜单按文字、有效快捷键和内边距测宽。保留 Windows 圆角、轻分隔线和圆角选中底色。

## 7. 贴图

参考 04-pinned.png。

- 图片为主体，无普通窗口标题栏，轻阴影、细边框、克制圆角。
- 小型悬停工具条只出现复制、保存、关闭，不出现标注工具。
- 菜单：复制、保存、恢复原始比例、分隔线、关闭。
- 缩放提示短暂显示，不能成为图像数据的一部分。
- 图片本身内容不添加示例图中的蓝色卡片样式，那是示例被截内容。
- 鼠标离开后隐藏悬停控件，事件驱动刷新。

## 7a. 新工具与长图

- 马赛克区域显示主题色控制点，拖区域移动、拖八点缩放，滚轮调颗粒；遮挡范围与颗粒大小必须分开标识。
- 编号使用真实红色圆环和数字，透明中心，按创建顺序连续编号；调整直径后仍居中，两位数不依赖 Unicode 带圈字符。
- 取色浮层显示色块和 HEX/RGB 字符串。提示是“Shift 切换”，不是“按住 Shift”；单击复制后仍停留，切换格式不改全局偏好。无放大镜。
- 长截图入口默认关闭。进入即丢弃旧对象、草稿和撤销/重做，不新增保留/迁移标注确认框。采集时只提供右侧预览、尺寸、完成和取消；普通参数滚轮暂停，正文滚轮交给原应用、预览滚轮只浏览预览。
- 长图完成后静态编辑，主画布滚轮调工具参数，右侧缩略图和滚动条浏览画布。预览优先放选区右侧，空间不足贴屏幕右边且排除出捕获，不擅自缩减选区。

## 8. 视觉验收

运行真实应用，至少留存下列截图到忽略的 artifacts/visual 目录：

1. 浅色下的截图选区、工具条与参数条。
2. 深色下的截图选区、工具条与参数条。
3. 文字中文输入与已选中对象的状态。
4. 通用、快捷键、外观设置页。
5. 多张贴图、菜单、缩放提示。
6. 150% 或 200% 缩放下的工具条和设置窗口。
7. 各新增工具、圆角透明/白底实际输出、长截图采集及完成后的长图编辑，对照新版 S01–S09 草图。

对照设计稿检查：工具顺序、控件比例、留白、圆角、图标重量、文字可读性、hover/focus/disabled、边缘定位和主题一致性。

禁止把设计 PNG 当作实现截图提交。视觉错误与功能错误一样需要修复；如运行环境无法真实截图，明确标注未验证。

逐功能执行 [验收计划](ACCEPTANCE_PLAN.md)，对应报告使用 [统一模板](validation/FEATURE_ACCEPTANCE_TEMPLATE.md)。本次只验证草图文件与文档，不将应用功能或 GUI 记为通过。
