# kiki 视觉与交互基线

用户已批准本目录设计参考所展示的方向。实现必须保持这一套视觉语言，不能另起一套未经批准的 UI。

## 1. 参考资料与解释顺序

1. 用户后续明确要求。
2. PRODUCT_SPEC.md 的功能行为与本文设计约束。
3. docs/design/01-capture.png 至 04-pinned.png 的视觉方向。
4. 平台惯例和合理实现选择。

参考 1Capture 的浮动工具条、上下文工具参数、悬停提示和截图后直接输出流程：

- https://1capture.com/
- https://1capture.com/docs

四张图由内置图像生成工具制作，不是实际软件截图。图中示例文档、壁纸、任务栏、假日期、示例文件名、无关的背景文字均不是需要实现的 UI。

尤其注意：截图示例文档对“窗口吸附”的描述不是产品定义；本项目中的吸附是选择窗口边界，而不是拖动窗口靠屏幕边缘。

## 2. 设计语言

- Windows 11 风格：圆角、柔和阴影、细边框、适度半透明。
- 设置、托盘和截图共用松绿强调色。浅色为 #365F56，深色为 #A0CEBB。强调用于当前工具、选区、焦点和主操作。
- 标注默认红色，其他预设颜色按标注内容选择。
- 浅色与深色均采用暖灰基调，浮动工具条保留细边框。
- 使用一致的单线图标，避免 Emoji、混合图标风格和依赖远程图标。
- 字体采用系统 UI 字体及中文回退；优先清晰可读，不随应用捆绑大型字体包。
- 透明效果只用于必要面板，保持文字对比。系统关闭透明效果或合成能力不足时可使用同色实色降级。
- 使用公开、受支持的系统能力；不依赖未文档化 API 制作模糊特效。
- 不使用连续装饰动画，界面静止时不持续消耗绘制资源。

## 3. 初始逻辑尺寸

以下为实现起点，以逻辑单位随 DPI 缩放，不照抄图片像素尺寸：

| 项目 | 建议 |
| --- | --- |
| 主工具条高度 | 48 DIP |
| 普通按钮命中区域 | 至少 36 × 36 DIP |
| 截图主条图标 | 以 01-capture.png 的轮廓为准，最长边约 18 DIP |
| 截图主工具条圆角 | 10 DIP |
| 普通按钮圆角 | 6 DIP |
| 参数面板圆角 | 10–12 DIP |
| 选区到工具条间距 | 8–12 DIP |
| 主工具条到参数条 | 6–8 DIP |
| 设置窗口初始尺寸 | 约 960 × 680 DIP，受当前工作区限制 |
| 设置侧栏 | 约 180–200 DIP |
| 设置内容边距 | 24 DIP |

不得为遵守某个尺寸而让按钮越界、文字被截断或工具条无处显示。小工作区可滚动设置内容。

## 4. 截图界面

参考 01-capture.png。

- 选区之外使用中性灰遮罩，选区内维持截图原色。
- 箭头从按下点拉向实心尖端。箭头与画笔无矩形外框，选中后分别显示端点和沿笔迹的高亮。
- 文字输入框无底色，细边框随文字宽度和行高变化。选中文字后可拖动，顶部圆点用于自由旋转。双击重编时文字暂时水平，提交后恢复角度。
- 松绿色细选区线带中性衬边，八个调整点用主题底色填充。标注对象调整点用实心强调色区分。
- 尺寸标签用实际成图物理像素，不显示逻辑尺寸冒充像素。
- 工具条在选区下方居中；不够则上方；再不足则收纳到可用屏幕内，并保证点击可达。
- 跨屏时将整个工具条放在合适的一块屏幕上，不能停在显示器间隙中。
- 主工具条、参数条、提示都不能进入最终合成图片。
- 屏幕左下可显示轻量快捷键提示，熟悉后可在设置中关闭。

## 5. 工具条与参数条

截图主工具条的比例、留白和图标轮廓以 01-capture.png 为准。参数状态参考 02-toolbars.png，颜色使用共用暖灰与松绿。

固定顺序：

选择、矩形、箭头、画笔、文字 | 撤销、重做 | 贴图、保存、复制 | 取消

- 共 11 个主要控件。复制为松绿主按钮，保留“复制”文字；其他默认图标形式。
- 将参考图中约 880×68 像素的主条归一到 48 DIP 高。普通按钮中心间距约 46 DIP，三个分隔线位于文字、重做和复制之后。普通按钮命中区为 42×36 DIP。主条保留细边框，无底部硬阴影。
- 当前工具与参数使用松绿圆角高亮。悬停、按下、禁用和键盘焦点分别呈现。
- 撤销和重做不可用时禁用，不删除按钮以免布局跳动。
- 悬停显示名称与已实现的快捷键，不显示未实现的按键说明。
- 参数条根据工具出现。选择工具可不显示绘图参数。
- 矩形/箭头/画笔：预设颜色与粗细；文字：颜色、字号。
- 预设颜色建议红、橙、黄、绿、蓝、紫、白、黑。黑白在不同主题下有可见边框。
- 每个工具的参数变化即时预览，统一与导出结果匹配。
- 工具条两种主题必须都实现。不要只做深色再反转颜色。

## 6. 设置窗口

以 [新版设置效果图](design/05-settings-layout.png) 为视觉参考。03-settings.png 保留为早期稿。

- 设置标题栏左侧留空，右侧保留 Windows 的最小化、最大化和关闭按钮。侧栏品牌标识与程序和托盘共用内嵌应用图标。导航图标采用同一套线性样式。
- 设置和托盘菜单使用暖灰背景和松绿强调色。设置字号为 24、16、14 和 12 DIP。右侧用标题、对齐和留白组织内容，只在大的功能模块之间使用细分割线。
- 通用页首先提供开始截图按钮，旁边只显示已成功注册的快捷键。开机启动单独分组，固定输出说明放入使用帮助。普通行高 42 DIP，内容超出窗口时可滚动。
- 截图页分为操作提示和默认标注样式。使用真实开关、颜色色点、线宽样例和字号选项。外观页用三张等宽主题缩略图，选中标签显示松绿色勾选标记。
- 保留通用、快捷键、截图、贴图、外观、关于六个页面及现有设置动作。快捷键以文字显示当前组合，聚焦后提示直接按下新快捷键，成功后返回当前组合。固定 PNG 等行为用静态文字说明。
- 键盘焦点有独立提示，Tab 可滚动到屏外控件。保存状态区固定在底部，分别显示待更改、保存中、成功或失败；失败提供重试。
- 托盘右键菜单按文字、有效快捷键和内边距测宽。保留 Windows 圆角、轻分隔线和圆角选中底色。

## 7. 贴图

参考 04-pinned.png。

- 图片为主体，无普通窗口标题栏，轻阴影、细边框、克制圆角。
- 小型悬停工具条只出现复制、保存、关闭，不出现标注工具。
- 菜单：复制、保存、恢复原始比例、分隔线、关闭。
- 缩放提示短暂显示，不能成为图像数据的一部分。
- 图片本身内容不添加示例图中的蓝色卡片样式，那是示例被截内容。
- 鼠标离开后隐藏悬停控件，事件驱动刷新。

## 8. 视觉验收

运行真实应用，至少留存下列截图到忽略的 artifacts/visual 目录：

1. 浅色下的截图选区、工具条与参数条。
2. 深色下的截图选区、工具条与参数条。
3. 文字中文输入与已选中对象的状态。
4. 通用、快捷键、外观设置页。
5. 多张贴图、菜单、缩放提示。
6. 150% 或 200% 缩放下的工具条和设置窗口。

对照设计稿检查：工具顺序、控件比例、留白、圆角、图标重量、文字可读性、hover/focus/disabled、边缘定位和主题一致性。

禁止把设计 PNG 当作实现截图提交。视觉错误与功能错误一样需要修复；如运行环境无法真实截图，明确标注未验证。
