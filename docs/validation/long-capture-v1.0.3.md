# v1.0.3 长截图修复验收

2026-11-12。候选基于 `v1.0.2`，被测应用代码随本报告提交。

## 回归结果

| 检查 | 实际结果 |
| --- | --- |
| 滚轮经过临时浮层 | 在旧实现上复现一次输入触发停止消息。修复后使用同一 Win32 文档和浮层，浮层内的滚轮不再停止采集。移回正文，滚轮转发到原生 EDIT，首个可见行发生变化。 |
| 从工具条启动并保存 | 在 Windows 桌面会话用 Release 测试程序点击真实工具条中的长截图按钮。保留原选区，选区中心命中源应用。经一次合成滚轮输入，实时预览由 286 px 增至 325 px。点击完成并保存，解码的 496 × 325 px PNG 与拼接底图逐像素一致。 |
| 首帧失败 | 在沙箱内用同一原生窗口覆盖 Windows Graphics Capture 无法开启的路径。失败后恢复完整框选区域，清空失败选区，并可按 Esc 退出。 |
| 跨屏重选与整屏边界 | 模拟跨屏后要求拖动重选，单击整窗候选不会恢复窗口吸附，Esc 结束会话。整屏选区的 Win32 区域测试验证正文保持开放，预览区仍可命中。 |
| 其他回归 | Windows 桌面会话默认和全特性串行套件最终各 82 通过、6 项按需运行。另行运行本次两项原生用例。rustfmt、全特性 Clippy 与 Release 打包通过。沙箱测试的热键及系统权限缺项和并发启动套件时出现的剪贴板错误，均在单套件运行时通过。 |

原生滚轮至预览更新单样本为 45.7 ms。Windows 11 x64 build 26300，Intel Core i5-12400，测试显示器 3420 × 2138、200%、144 Hz、SDR。该样本为 Release 测试窗口通过滚轮回调到预览数据更新的时间。
