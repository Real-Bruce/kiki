# v2.0.1 通用页与导航修订验证

2026-11-25，基于 `4207a8c` 的界面升级候选，按用户本次截图标记及 `keyboard-outline.svg` 调整。实现保持 Rust 1.88.0／2024、Win32／Direct2D，不增加依赖。

## 本轮改动

- 删除通用页整个开始截图分组，包括按钮、快捷键提示与操作说明；真实子控件也不再创建。通用页仅有启动与后台、设置文件。
- 自启开关单独一行；应用移动时，以细分隔线隔开次要提示，再在提示下方左对齐显示更新按钮，避免两个控件纵向挤在一起。移除用户指定的“关闭设置后，仍可从任务栏右下角的 kiki 图标开始截图。”。
- 快捷键导航保留用户 SVG 的两排各五个按键和空格键，将外轮廓转为共享 A 版圆端描边；截图导航恢复两条交叉裁切线。两者使用 24 DIP 网格、1.65 DIP 描边和主题颜色。
- 同步关于页、快捷键冲突、README、包内快速说明和当前规格中的截图入口，改为热键或托盘。移除已失去 UI 调用方的开始截图请求函数和专用按钮状态，保留已有捕获与失败恢复实现。
- [用户 SVG 参考原件](../../design/redesign/keyboard-outline-reference.svg)与输入字节一致，SHA-256：`a2095ea44711c4c220dfa3326a66c87078b0558f90514b8006f3fc21ebe3caef`。参考文件不在运行时加载或随 ZIP 分发。

## 实测环境与界面

Windows 11 `10.0.26300.9974`，MSVC x64 Release diagnostics；真实设置窗口 DPI 192（200%），通过只读 `GetDpiForWindow` 查询。独立配置为忽略目录 `artifacts/settings-refinement-v2.0.1-config`。

真实[浅色通用页](../../screenshots/settings-refinement-v2.0.1/general-light.jpg)、[深色通用页](../../screenshots/settings-refinement-v2.0.1/general-dark.jpg)已检查并保留。工具按逻辑坐标输出 JPEG，约 949×815；不是原始物理像素图。

- 已确认开始截图分组和指定提示不存在，两个分组从内容顶部自然排列，底部保存状态正常。
- 当前机器存在旧启动位置，因此实际看到开关、移动提示和下方修复按钮；两种主题下按钮间距、说明层级与圆角面板清楚。没有点击自启开关或更新按钮，不修改用户启动项。
- 导航两个新图标在浅深前景下均可辨认，风格与其余导航一致；真实导航控件仍可切换页面。
- 正式解压版逐页检查快捷键、截图、贴图和外观，键盘与裁切线的松绿选中状态正确；四张浅色实拍已收录本轮目录，并用于更新双语 README。原有 Ctrl+1 和用户工具参数继续读取。
- 原有配置和截图功能由既有串行套件回归。本次未重新进行手动截图输出或性能采样，不沿用旧版 GUI／性能结论冒充本轮新测。
