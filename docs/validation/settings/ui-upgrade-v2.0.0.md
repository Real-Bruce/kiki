2026-11-25。实施依据为[整体升级方案](../../design/redesign/UPGRADE_PLAN.md)。本次实现 B 版分组排版、原有暖灰松绿配色及最终 A 版图标；源码分支为 `codex/ui-icon-upgrade`，图标阶段提交 `dd70494`，设置与控件实现提交 `660b218`。本报告随后补充实际运行证据，不改变被测应用代码。

## 实现与范围

- 六页设置使用共用圆角面板与真实 Win32 子控件布局；面板间隔 16 DIP、内边距 20 DIP、分组标题 18 DIP。说明文字通过 DirectWrite 测量换行，底部保存状态固定。
- 截图、设置预览、工具复选框、贴图均使用同一套原生 Direct2D 图标；马赛克为 3×3 等大双色实心块，绘制后恢复画刷透明度；长截图为两条圆端向下折线。导航也采用相同线宽与圆端。
- 主题预览选中边框、颜色选择外环、设置与截图滑杆圆点统一为松绿反馈。原有工具顺序、开关默认值、历史、长截图进入语义、输出算法和配置格式保持已有行为。
- 无应用依赖增加；Rust 1.88.0、2024 edition、Windows 原生技术栈。限制原本仅供诊断演示使用的贴图入口为 diagnostics 编译，消除普通构建的未使用函数告警。

- Windows 11 专业版 `10.0.26300.9974`，Intel Core i5-12400，12 个逻辑处理器。
