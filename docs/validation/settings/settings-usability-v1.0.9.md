# v1.0.9 设置界面验收

2026-11-13。Windows 11 x64 build 26300.9974，Intel Core i5-12400，单屏 125% 缩放。使用 Rust 1.88.0 MSVC Release 诊断副本，在独立实例与配置目录中验证设置窗口。

## 设置窗口

- 使用 Windows Graphics Capture 查看浅色通用页、外观页和截图页，以及深色截图页、快捷键页、贴图页、外观页和关于页。通用页可直接看到开始截图、有效快捷键及框选和输出提示。快捷键录入框在实机检查后补加边框，重新构建并查看了普通和聚焦状态。
- 深色截图页开启马赛克后，工具条立即出现对应图标，默认标注样式显示 12 px 颗粒大小及 2–64 px 范围。圆角滑杆改到 139 px，数值框与 PNG 圆角预览同步。取消恢复默认后保留 139 px。重启时读取到深色、139 px 圆角和马赛克开关。
- 依据实际调色板计算，浅深主题的辅助文本对背景对比度分别为 6.20:1 和 8.65:1，滑杆未填充轨道对背景分别为 3.60:1 和 3.27:1。键盘焦点沿用松绿轮廓。屏幕阅读器与其他缩放比例待验。
- 用户中止桌面操作，手动截图后复制粘贴、另存为或贴图的完整链路待补。原生自动回归通过 PNG、JPEG、贴图及保存失败恢复用例。本轮界面图通过桌面检查查看，README 暂保留既有公开截图。
