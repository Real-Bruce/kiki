# v1.0.8 截图设置滑块闪烁验收

2026-11-13。Windows 11 x64 build 26300.9974，Intel Core i5-12400，单屏 1920 × 1080 SDR、125% 缩放，Rust 1.88.0 MSVC。

## 复现与修正

- 用户录屏中，拖动圆角、编号、马赛克和字号滑块时出现局部闪烁。v1.0.7 的浅色原生窗口可短暂丢失「外观」导航按钮，深色窗口可短暂丢失未操作的画笔线宽滑块。 [浅色复现](settings-slider-v1.0.8/before-light.png) · [深色复现](settings-slider-v1.0.8/before-dark.png)
- 参数变更时只标记受影响的滑块、数值框与圆角示意。更新原生数值框时暂缓其独立重绘，随后与滑块一起缓冲提交。保存状态一般只刷新页脚，出现或移除「重试保存」时更新布局。 [Microsoft WM_SETREDRAW 文档](https://learn.microsoft.com/windows/win32/gdi/wm-setredraw)

## 实测

- Release 诊断副本使用独立配置，在七条滑块上各选 15 个参考位置，发送按下、移动和抬起消息。每种主题每条滑块在拖动中收到 97 条移动消息，间隔 20 ms，并插入 240 ms 停顿让后台保存回执在拖动中到达。Windows Graphics Capture 采集 1154 × 899 的客户区样本，覆盖侧栏和内容区，排除滚动条、窗口外框及会正常切换提示文字的页脚。
- 浅色 872 帧、深色 852 帧均逐像素匹配对应参考位置，七条滑块各采到全部 15 个位置。相同脚本在 v1.0.7 深色采到 17 帧可见异常。候选版每条滑块的移动消息往返均值为 1.38–1.80 ms，包含测试线程调度与原生输入处理。 [浅色字号](settings-slider-v1.0.8/light.png) · [深色字号](settings-slider-v1.0.8/dark.png)
- 因旧版实例正在运行，实际鼠标与输出检查在独立实例的 Release 诊断副本执行。两种主题均拖动线宽与字号。深色数值框回车提交 32 px，聚焦时滚轮增加到 33 px。重启后深色、矩形 42 px、箭头 32 px 和字号 33 px 保留。框选设置窗口并输出 1184 × 1012 的实际贴图，核对滑块和数值，Esc 关闭贴图。
- 格式检查和全特性 Clippy 通过。默认与全特性套件各 82 项通过、6 项跳过。原生回归覆盖拖动上下限、数值框同步、同值消息跳过重绘、保存回执只标记页脚及失败重试。初次回归将可见更新区断言放在隐藏窗口，修正测试前提后又遇到 GUI 复测实例占用 F17，释放热键后两套串行测试通过。其他实机缩放待补测。
