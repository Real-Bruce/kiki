## 实现与产物

- 截图设置的「图像输出」提供 0–256 px 滑杆、整数输入和透明角示意。滑杆获得焦点后可用方向键与滚轮按 1 px 调节。旧配置缺少字段时使用 0 px，复用异步写入器。
- 选区半径为设置值与短边一半中的较小值，几何仍用物理像素。预览压暗裁去的区域并裁切标注，外接矩形控制点可继续拖动。原生文字草稿使用 GDI 区域裁切，已提交标注和成图采用抗锯齿边缘。
- 后台成图先合并底图和标注，再对四角应用覆盖率。半透明像素保留原 RGB，完全透明处清零。PNG、剪贴板与贴图共用该结果，贴图后续保存和复制直接使用原贴图图像。
- Windows 11 专业版 build 26300，i5-12400（12 逻辑处理器），约 32 GiB RAM，Intel UHD 730 驱动 32.0.101.7088，单屏 1920×1080、60 Hz、125%。Rust 1.88.0/MSVC x64。测试使用独立配置目录。
- 正式 Release EXE SHA-256 `6DE2AF09A39FB2E36FEA5ED7C4BCE1C047D20E198AFE1E588542E4476CAFAA32`。ZIP 解压得到 16 个文件，`kiki.exe` 为 0.6.0，哈希与构建产物一致，内含更新的使用说明。诊断版 EXE SHA-256 `23310B0201DA32A069C008E26EBA631660BA6EAC89D7A409F6F539A284C014F7`。
- 候选包 `dist/kiki-v0.6.0-windows-x64.zip`，SHA-256 `5960190D132CB44F19E48A2DFF5C75B53AB943CAB2B65B154BCF406436F5A0C6`。本报告随构建输入所在的实现提交入库。正式包解压后的独立启动烟测待补。
