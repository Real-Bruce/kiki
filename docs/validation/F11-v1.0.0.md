目标版本 **v1.0.0**。2026-11-12 提供 Windows 11 x64 候选包。单元测试、性能诊断和包内容校验由 Codex 执行，界面与功能由用户实机验收。用例依据见 [F11 验收计划](../ACCEPTANCE_PLAN.md#f11) 和 [S07、S08 草图](../design/next/README.md)。

## 快速滚动修订

用户确认外围遮罩修复，稍快滚动时仍会提示找不到可靠接缝。旧版每轮重新开启 Windows Graphics Capture 并等待两帧近似静止，连续滚动时可能跳过有重叠的中间位置。

修订版在同一次采集中复用两帧的 Windows Graphics Capture 帧池、选区大小的 GPU 读回纹理和一份像素缓冲。轮询预览以合并后的最新结果显示，采集线程在滚动中持续尝试对齐。滚动收尾时若最后一帧仍无法可靠匹配，保留此前已确认的图像并提示回到已捕获位置。

默认及全特性单元测试各 78 项通过，默认测试集中忽略真实剪贴板和原生性能夹具。严格 Clippy、rustfmt 和 Git 差异检查通过。单元用例构造 360 px 总位移，直接跨越时拒绝，依次输入四个中间帧时能恢复连续图像。

另以 Release 测试程序测量 Windows 原生捕获。前台不激活的 420 × 260 px GDI 测试窗连续更新 36 次，每次推进 83 px。计时从测试窗开始绘制到 WGC 读回并拼接完成，覆盖 GDI/DWM、GPU 读回与接缝匹配。首帧就绪为 54.705 ms，36 次更新 P50 为 16.232 ms、P95 为 32.586 ms、最大 34.271 ms。最终 420 × 3248 px 与程序生成的完整长图逐像素一致。首次原生运行暴露空帧池在 windows-rs 中返回空错误的情况，补齐处理后复测通过。保留日志 `native-stream-first.log` 和 `native-stream.log`。

同机 diagnostics Release 另跑完 100 轮合成长图生命周期。680 次干净帧拼接与缩略图 P95 为 3.439 ms，140 次带边缘变化与重绘的短帧 P95 为 1.526 ms，30 次分带合成与 PNG 内存编码 P95 为 419.806 ms。两项上限仍分别停在 32768 px 与 256 MiB。边界测点私有提交最高 278.94 MiB。结束后闲置采样 61.935 秒，私有工作集最高 4.94 MiB，归一化 CPU 约 0.25%，含诊断采集开销。夹具计算与资源采样不含真实应用滚轮、界面呈现或磁盘写入。

当前候选 ZIP 为 `dist/kiki-v1.0.0-windows-x64.zip`。已核对解压 16 个文件、EXE 版本 1.0.0、PE x64 及构建产物一致性。ZIP SHA-256 为 `78e7d1a2f3a85d8f52613c2b20a9da17fcb6e4d0ea0d5ffae5df3ba2b1870820`，EXE SHA-256 为 `b0ffd8b9a865746a906f9bd010898d012e2f6838eb11fb80a7389997e8e1b9fb`。性能诊断 EXE SHA-256 为 `42204eb925bc765d93b778f9e132f055428c66fcc758c16c5f0a4e90d54ed3d6`。包校验、单元日志、性能 CSV、环境及前一候选归档位于 `artifacts/validation/f11-2026-11-12-fast-scroll/`。

## 遮罩与接缝修订记录

用户在首个候选中发现，点击长截图后外围遮罩消失，滚动后右侧预览没有增长并提示找不到可靠接缝。原窗口区域只保留边框和预览。原接缝校验要求整个重叠区逐像素相同，滚动条滑块和局部重绘也会导致失败。

- 采集时保留选区外的半透明视觉效果和选区边框，正文区域露出实际滚动窗口。遮罩与预览沿用 Windows 捕获排除。预览贴右时如果会完全盖住正文选区，就放在选区左侧。
- 滚轮按短暂停顿或最长等待调度采样。目标窗口位于前台时使用 Windows 原生滚轮路由。稳定性判断忽略窄边栏变化，接缝优先逐像素校验，其次比较正文多个水平区段的内容及行间变化。只有唯一可信匹配才能追加。
- 请复验点击长截图后外围是否变暗、正文是否实际滚动、右侧预览及高度是否增长。可用带可见滚动条的网页或原生文档连续滚动三屏，再回滚、滚到底并保存，检查重复行及遮罩或预览是否混入输出。

## 首个候选性能

以下均为 x64 diagnostics Release。长图诊断使用固定的程序生成 BGRA 帧。计时从完整候选帧可用开始，测到拼接与缩略图生成结束。输出计时从整图分带合成开始，结束于 WIC PNG 内存编码完成，图片为 640 × 7200 px，含圆角和三处矩形。采集线程、滚轮投递、DWM 呈现、文件写入和实际剪贴板不计入这两项。

100 轮固定夹具覆盖 30 轮拼接后输出、35 轮无匹配后释放和 35 轮直接释放。追加分别停在 8 × 32768 px 和 4096 × 16384 px，后者原始像素为 268435456 字节（256 MiB）。输出缓冲测点私有提交最高 67.16 MiB，容量边界测点最高 279.06 MiB。结束后 60 次采样中私有工作集最高 5.02 MiB，私有提交最高 6.52 MiB。63.324 秒内含进程内 DXGI 与资源采集的 CPU 总时长为 3.250 秒，按 12 个逻辑处理器折算约 0.43%。这是诊断进程含采集开销的数值，普通托盘闲置指标单独记录。没有清理工作集。
