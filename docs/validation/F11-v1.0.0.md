# F11 验收报告 · 单屏纵向手动长截图

目标版本 **v1.0.0**。2026-11-12 提供 Windows 11 x64 候选包。单元测试、性能诊断和包内容校验由 Codex 执行，界面与功能由用户实机验收。用例依据见 [F11 验收计划](../ACCEPTANCE_PLAN.md#f11) 和 [S07、S08 草图](../design/next/README.md)。

## 实机反馈修订

用户在首个候选中发现，点击长截图后外围遮罩消失，滚动后右侧预览没有增长并提示找不到可靠接缝。原窗口区域只保留边框和预览。原接缝校验要求整个重叠区逐像素相同，滚动条滑块和局部重绘也会导致失败。

- 采集时保留选区外的半透明视觉效果和选区边框，正文区域露出实际滚动窗口。遮罩与预览沿用 Windows 捕获排除。预览贴右时如果会完全盖住正文选区，就放在选区左侧。
- 滚轮按短暂停顿或最长等待调度采样。目标窗口位于前台时使用 Windows 原生滚轮路由。稳定性判断忽略窄边栏变化，接缝优先逐像素校验，其次比较正文多个水平区段的内容及行间变化。只有唯一可信匹配才能追加。
- 请复验点击长截图后外围是否变暗、正文是否实际滚动、右侧预览及高度是否增长。可用带可见滚动条的网页或原生文档连续滚动三屏，再回滚、滚到底并保存，检查重复行及遮罩或预览是否混入输出。

修订候选 ZIP 位于 `dist/kiki-v1.0.0-windows-x64.zip`。已解压核对 16 个文件、EXE 版本 1.0.0、PE x64 及构建产物一致性。ZIP SHA-256 为 `7283743e28d78b33a793a3291cb17fd74ba221c43cb07a568ee92174d4d4b55d`，EXE SHA-256 为 `54a8e18409a7af2569235c6201c63a916f962762e068468b099560fb5e4ca2f2`。

默认及全特性单元测试各 79 项通过、1 项真实剪贴板用例忽略。新增用例覆盖 Windows 遮罩区域、连续滚轮调度、移动滚动条与局部重绘、正文未停稳及重复图案。rustfmt、严格 Clippy、Release 构建及 Git 差异检查通过。

## 首个候选性能

以下均为 x64 diagnostics Release。长图诊断使用固定的程序生成 BGRA 帧。计时从完整候选帧可用开始，测到拼接与缩略图生成结束。输出计时从整图分带合成开始，结束于 WIC PNG 内存编码完成，图片为 640 × 7200 px，含圆角和三处矩形。采集线程、滚轮投递、DWM 呈现、文件写入和实际剪贴板不计入这两项。

| 指标 | 样本 | P50 | P95 | 最大 |
| --- | ---: | ---: | ---: | ---: |
| 拼接与缩略图 | 820 | 1.080 ms | 3.379 ms | 11.348 ms |
| 分带合成与 PNG 编码 | 30 | 442.936 ms | 527.175 ms | 536.674 ms |

100 轮固定夹具覆盖 30 轮拼接后输出、35 轮无匹配后释放和 35 轮直接释放。追加分别停在 8 × 32768 px 和 4096 × 16384 px，后者原始像素为 268435456 字节（256 MiB）。输出缓冲测点私有提交最高 67.16 MiB，容量边界测点最高 279.06 MiB。结束后 60 次采样中私有工作集最高 5.02 MiB，私有提交最高 6.52 MiB。63.324 秒内含进程内 DXGI 与资源采集的 CPU 总时长为 3.250 秒，按 12 个逻辑处理器折算约 0.43%。这是诊断进程含采集开销的数值，普通托盘闲置指标单独记录。没有清理工作集。

长图性能原始数据见 `long-performance/long-latency.csv`、`long-performance/long-resources.csv` 与 `long-performance/long-idle.txt`。普通性能首次使用默认键时注册失败，失败样本保留在 `startup/`。后续性能采样使用隔离配置内的 `Ctrl+Alt+Shift+F10`。

普通截图性能实际枚举到 1 块 1920 × 1080、125%、60 Hz 的 SDR 屏幕。启动以进程创建到热键注册与托盘就绪计时。截图从软件投递已注册热键消息，到实际遮罩首次绘制及 DWM 完成计时。

## 人工验收

| 用例 | 操作 | 待核对 |
| --- | --- | --- |
| F11-AC-001 | 普通截图内添加标注，启用长截图并分别完成或取消 | 旧标注、文字草稿和历史无法恢复。下一次从普通截图开始 |
| F11-AC-002、005 | 单屏框选正文，向下滚动至少三屏，回滚再向下，到底后继续滚动 | 右侧预览只增加可靠的新行，回滚和到底不会重复拼接 |
| F11-AC-003 | 框选跨屏区域后选择长截图 | 明确提示改选单屏。另开普通截图回归跨屏 |
| F11-AC-004 | 框选重复纹理、动态内容或固定页头，再做快速滚动 | 不可靠时提示暂停，已拼接内容可用 |
| F11-AC-006 | 在正文、采集预览、长图主画布、右侧缩略图与参数区分别滚动 | 滚轮只触发该区域的操作。缩略图、滚动条支持点击和拖动 |
| F11-AC-007 | 完成后在顶部、中部、底部标注、编辑、编号与取色 | 操作定位准确，输出包含整张长图及各处标注 |
| F11-AC-008 | 检查接近两项上限的实机行为 | 已有图像保留，停止增加；自动性能夹具已触及两项边界 |
| F11-AC-009 | 捕获时移动或关闭目标，取消后立刻重开 | 已采集内容不混入失效帧，新会话不接收旧帧 |
| F11-AC-010 | 保存 PNG/JPEG、复制粘贴和贴图，取消保存后重试 | 整图、接缝、圆角和标注正确。失败后保留长图编辑 |

| F11-AC-012 | 真实应用滚轮至预览，以及长截图全链路生命周期 | 合成夹具的时延与资源已记录。真实目标滚轮、呈现和长截图全链路仍需实机采样 |
