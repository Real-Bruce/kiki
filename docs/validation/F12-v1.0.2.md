## 恢复撤销按钮后的复测

- 普通截图和长图编辑在绘图与采集工具之后、输出之前显示撤销按钮。无历史时保留禁用图标，设置预览也显示禁用图标。窄屏收纳绘图与采集工具时撤销仍直接可达。
- 原生窗口用例 `undo_button_is_visible_and_uses_history_in_both_editors` 覆盖两个编辑器中禁用时点击、有标注时鼠标撤销、按 Enter 激活及撤空后再次禁用。布局回归覆盖 256 种工具开关组合、四档模拟 DPI、窄屏及无绘图工具的情况。
- 格式、全特性严格 Clippy、默认与全特性测试通过。两套测试各 82 项通过、4 项跳过。修订版实机浅深截图和实际输出待复验。上一次候选的截图和成图见下文。
- 修订版 Windows x64 ZIP 位于 `dist/kiki-v1.0.2-windows-x64.zip`，SHA-256 为 `afff7a5ce46d6a1a921115315c3fcb228ae844171b18fe5e2d1711b1dfa9fd96`。解压 16 个文件，EXE 为 x64，版本为 1.0.2，SHA-256 为 `b0e32496be11c689d19226e37f32e2027fba6cc2b822c656b7d63c028e8f6721`，与 Release 构建一致。日志和清单位于 `artifacts/validation/f12-undo/`。

## 自动回归与证据

- `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`、`git diff --check` 通过。默认和全特性测试串行各 81 项通过、4 项跳过。跳过项为两项真实剪贴板、两项可见长图采集夹具。初次沙箱执行遇到热键和注册表权限失败，并发现一个测试仍期望焦点停在撤销按钮。更新该测试后在正常 Windows 会话重跑，两套均通过。
- 公共回归覆盖 COM-AC-001 的构建检查，COM-AC-003、004、005、006、007 的自动部分，包括 PNG 像素、JPEG 白底和尺寸、贴图图像、保存取消／失败重试、剪贴板占用、会话代次、设置迁移与恢复。真实窗口、实际粘贴、实机输入及安装环境缺项保留。
- COM-AC-008 的候选包检查通过。初次校验把文本 `FileVersion` 错比为四段，复核文件版本字符串为 `1.0.2`、固定版本字段为 `1.0.2.0`。解压共 16 个文件，合计 1,839,944 字节，EXE 为 x64，包内 EXE 与 Release 构建产物哈希相同。
- F12 只修改共享工具条、绘制状态与事件入口，沿用 F11 的采集、拼接、成图、文件和资源生命周期路径。未重采 F11 的长截图与资源性能指标。历史性能与 200% 时延波动见 [F11 验收](F11-v1.0.0.md) 和 [P7](P7.md)。
