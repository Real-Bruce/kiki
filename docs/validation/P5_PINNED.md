# P5 第二批：多张置顶贴图

日期：2026-11-06。以下保留第二批的历史验证结果；后续已完成资源修正与输出验收，当前状态见 [P5 完成验收](P5_COMPLETION.md)。P3 继续按用户要求暂缓。

## 实现

- 截图工具条贴图按钮及 Ctrl+P 接到后台干净合成；当前文字先提交。独立贴图创建成功才结束截图，创建失败返回原编辑状态。贴图动作本身不写文件或剪贴板。
- 多张 WS_EX_TOPMOST / WS_EX_TOOLWINDOW 原生无标题栏窗口，细边框、小圆角、阴影；悬停仅显示复制、保存、关闭，离开隐藏。右键菜单为复制、保存 PNG、恢复原始比例、关闭。托盘增加关闭所有贴图，应用退出也关闭贴图。
- 拖动使用系统窗口移动循环；滚轮以鼠标所在图像位置缩放；Ctrl+0 或菜单恢复 100%。缩放比例提示 1.2 秒后消失。首次显示适配所在屏幕工作区，最小窗口 144×64 DIP，小图在其中居中，图像比例不变。
- 显示缩放约 1%–400%，单边不超过 8192 像素、显示面积约 16 MP；大图会采用更低上限，恢复 100% 受限时显示“显示上限”。这些限制只影响显示，复制/保存始终使用原图。
- 每张只持有裁剪后成图的 Arc<Image> 和显示资源，不持有完整桌面、编辑器或撤销历史；已有图像复制/保存直接进入原后台输出工作者，不重新合成或按显示大小重采样。
- 全局最多 64 张、按每窗口原始 BGRA 图像累计最多 512 MiB；该数值不代表整个进程内存。输出仍最多一个后台任务，关闭窗口会取消其任务。
- 使用共享的 UI 线程 Direct2D 工厂；最后一张关闭后释放工厂缓存，退出时再次清理。贴图最终使用软件 Direct2D HWND 表面，避免硬件目标在本机的更大资源缓存。COM/D2D 对象不跨线程，窗口及图像按生命周期回收，空闲不持续刷新或轮询鼠标。
- 无新增 crate、运行时或依赖功能。默认 Release 656,384 字节（比前一输出检查点增加 60,416 字节）；构建路径：target/p5-pin-checkpoint/x86_64-pc-windows-msvc/release/kiki.exe。

## 实际 GUI 和输出

- 浅色真实窗口已对照 04-pinned.png，使用明确的 640×360 测试成图验证两张并存。浅色完整交互记录来自硬件表面初版；切换软件表面后另实测深色悬停、110% 提示及复制，不能据此宣称整个交互矩阵已在两种主题重新验收。
- 滚轮从 100% 到 110%，Ctrl+0 回到 100%；真实拖动使物理窗口原点从 (850,298) 变为 (1010,378)。悬停工具条和原生右键菜单已实际显示。
- 110% 状态通过 Ctrl+C 复制，实际读取剪贴板 PNG、CF_DIBV5 与 CF_DIB；原始尺寸仍为 640×360，DIB 高度 -360 表示顶向下。
- Ctrl+S 打开原生另存为；输入 artifacts/p5-pin-gui-save.png 后实际点击保存，PNG 为 640×360、9,729 字节。文件 PNG 与剪贴板 PNG 的 SHA-256 一致：7E85A57B6C06AC07908FE281A49F8860C62C2D00EA6D93668B2BABB9E8BB26D1。最终软件/深色表面的 Ctrl+C 也得到同一哈希，说明显示缩放、控件与深色透明背景未污染输出。
- 第二次打开另存为后 Esc 取消，窗口仍保留，可继续操作。悬停关闭按钮关闭单张，另一张仍存在。
- Ctrl+Alt+A 实际进入截图，Ctrl+P 后出现真实桌面成图贴图，截图窗口退出，原贴图仍存在。本次实际选区为 3420×2042；不把框选自动化动作认定为任意小矩形验收。
- 右键菜单复制的首次键盘自动化没有改变剪贴板，后用 Ctrl+C 确认复制成功，因此菜单条目点击执行不标通过。原生对话框 set_value 返回不可设置，但坐标聚焦后的 type_text 和点击保存成功。
- 尝试启动画图进行应用粘贴时，电脑操作工具返回 `Computer Use app approval timed out`，没有改用其他 UI 通道绕过；通用应用粘贴仍待验收。
- 电脑操作的 type_text 可能覆盖剪贴板。输入路径后两次只读剪贴板探针遇到缺少图像格式并弹出受控错误，已清理探针进程；不将其算作贴图动作覆盖剪贴板，也不宣称本轮 GUI 已证明无剪贴板副作用。
- 证据位于忽略目录 artifacts/visual/p5-pin、artifacts/p5-pin-clipboard、artifacts/p5-pin-final-clipboard；测试进程已清理。测试图片与真实桌面证据分别记录，均未提交图像或个人屏幕内容。

## 4K 资源采样

环境：Windows 11 专业版 10.0.26300，Intel i5-12400，枚举到 GameViewer Virtual Display Adapter 与 Intel UHD Graphics 730（32.0.101.7088）。MSVC x64 Release diagnostics。没有清空工作集，也没有剔除样本。显示器的独立 DPI/多屏拓扑未重测。

命令：`kiki.exe --pin-stress artifacts/p5-pin-stress-release`。十轮，每轮四份独立 3840×2160 BGRA 测试图，创建真实隐藏窗口并实际执行绘制，再关闭全部、泵消息并采样；末尾等待两秒再采样。不是四张可见窗口的拖动性能或 GPU 显存测试。原始 CSV 保留全部 22 行；每组原图共 126.56 MiB，CSV 中 capture_ms 占位列始终为零。

- 初版每窗口创建硬件 D2D 工厂，句柄随轮数增长；共享工厂后句柄稳定但内存仍高。原始比较数据保存在 artifacts/p5-pin-stress、p5-pin-stress-shared、p5-pin-stress-software。
- 最终软件表面且关闭最后窗口释放工厂的采样：四张打开时句柄均 209，全部关闭后均 180；USER 对象从 13 回到 4，GDI 维持 10；初始尚未加载绘图子系统时为 155/3/7。
- 四张打开时 private bytes 为 357.58–435.35 MiB；每轮关闭后为 229.63–244.60 MiB；最终两秒后 244.60 MiB，工作集 261.11 MiB。关闭后确有回落且句柄不再逐轮增长，但内存没有回到初始约 2.51 MiB，仍需分析绘图/分配器缓存，不能作为闲置 ≤20 MiB 达标证据。
- 本探针未分离测量 GPU/桌面合成器占用。改用软件 Direct2D 不代表桌面合成完全不使用 GPU。
