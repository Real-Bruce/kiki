# P5 第一批：复制与 PNG 保存

日期：2026-11-06。本页记录 P5 第一批复制/保存。后续多张贴图已接通，当前状态见 [第二批贴图验证](P5_PINNED.md)，P5 仍未完全验收。

## 实现

- 工具条接通保存、复制；非文本输入且未用 Tab 聚焦控件时 Enter 复制，Ctrl+S 保存；文本输入中的 Ctrl+S 先提交文字。显式 Tab 焦点保留 Enter/空格激活语义。
- 输出时冻结编辑，后台合成、PNG 编码、文件写入与剪贴板重试。成功才销毁截图窗口；保存取消、对话框错误或输出失败时返回原编辑会话。
- 全进程最多一个输出工作线程和一份结果通道，不积压任务。底图用 Arc 共享，几何快照不包含撤销历史；后台不传递 COM/D2D 对象。窗口销毁会发出取消信号，工作者在合成、编码及提交前检查取消。
- 原生 IFileSaveDialog：PNG 类型、kiki_YYYYMMDD_HHMMSS.png 默认名、覆盖确认、目录存在检查；最近目录目前仅在本进程记忆，跨重启配置由 P6 接续。
- PNG 在目标同目录创建独占临时文件，编码成功后 MoveFileEx 替换目标。失败或取消清理本次临时文件，既有目标保持不变。进程被强制终止仍可能遗留临时文件，尚未做异常退出清理机制。
- 复制只写剪贴板，无图片落盘副作用。预先准备 DIBV5、传统 DIB 和内存 PNG，再尝试打开剪贴板；最多重试 5 次，每次 20 ms。DIBV5 为必需发布项，其他格式尽力发布；未转移的 HGLOBAL 由应用回收，已转移的由系统持有。参考：[微软剪贴板所有权说明](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-operations)。
- PNG/DIBV5 保留 alpha；传统 BI_RGB DIB 兼容表示将透明区域合成到白底。普通应用的具体格式选择仍需粘贴矩阵实测。
- 默认构建启用干净成图和 PNG 模块；只增加现有 windows crate 的 DataExchange、Memory、FileSystem、SystemInformation 绑定，无新 crate、工具链升级或大型运行时。默认 Release 595,968 字节，比前一检查点增加 69,632 字节。

## 实际 GUI 与剪贴板

- 本轮实际选区为窗口边界 3420×2042。测试环境已不同于早先记录的 1920×1080，未独立重测本轮 DPI、硬件或 HDR，不能套用旧 125% 环境结论。
- 工具条复制为蓝色主按钮，保存已启用、贴图仍禁用。保存按钮和 Ctrl+S 均实际打开原生“另存为”，显示 PNG 与真实默认文件名；Esc 关闭对话框后仍保留选区与工具条，可继续操作。
- 文件名自动化遇到缓存元素不可用；后续键盘/文本尝试没有填入目标路径，已用 Esc 返回编辑，没有将 GUI 保存成功标为通过。
- 返回编辑后按 Enter，工作者完成输出，截图窗口从枚举中消失。
- 退出原测试进程后，以 diagnostics 的只读 --inspect-output-clipboard 检查：PNG 存在，CF_DIB 可用，DIBV5 width=3420、height=-2042。诊断不清空或改写剪贴板。
- 实际打开从剪贴板读取的 PNG，内容是冻结的 Zed 文档窗口，没有工具条/选区线污染。图片位于忽略目录 artifacts/p5-clipboard/clipboard.png，元数据在 clipboard.txt。
- 界面证据在忽略目录 artifacts/visual/p5/。没有使用模拟剪贴板或设计图替代真实结果。
