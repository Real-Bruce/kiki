## 拼接回归

精确搜索先检查重叠是否有足够的匹配细节，再统计候选数。除了已有的至少四种行指纹，也允许使用两处隔开的宽边界定位。每处边界必须有至少两个水平区段发生变化，且重叠区仍须逐字节相同。两处有细节的不同候选同时成立时暂停。完全相同的视口维持原位。

- 1057 × 362 px 视口向下 60 px。唯一带纹理的候选与 36 个纯色候选并存。修复后增加 60 行，结果与源文档逐像素相同。
- 同尺寸视口向下 16 px。重叠仅含背景和一条横带。修复后正确拼接，回滚不增加高度。重复横带出现多个有效候选、完全空白或移出已知区域时，保留原成图。
- 上述两条新增回归在旧实现上均返回 `Unmatched`，修订后通过。格式检查、全特性严格 Clippy、默认和全特性串行测试通过。两套测试各 86 项通过、6 项按需运行。

## README 原图重放

将两张 PNG（通用、快捷键）的每一行按原图步长读出，取 x=15 起的 1057 px，顺序拼成 1946 行的源图。用实际拼接器从顶部逐步下移 16 px，末帧对齐底部。

| 视口高 | 基线与本版结果 |
| --- | --- |
| 362 px | 首次拒绝在 y=416，保留 762 行，与源图前 762 行逐像素一致 |
| 520 px | 首次拒绝在 y=416，保留 920 行，与源图前 920 行逐像素一致 |
| 620 px | 无拒绝，成图 1057 × 1946 px，与源图逐像素一致 |

短选区经过长留白时仍会失去可定位的内容。362 px 样本的首次拒绝帧即使逐字节匹配，能定位的边缘像素也很少。经过整屏空白后，多种位移可产生相同帧。可重新框选更高的正文区域，让滚动前后有可匹配的文字或图像边缘。620 px 是本离线样本的通过尺寸，实际场景取决于布局和显示缩放。用户截图里的 IDE 现场及 Codex Daily 页面待复验。
