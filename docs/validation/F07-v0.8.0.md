## 共用回归与证据

- **格式、构建与测试。** `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`、默认及全特性 `cargo test --workspace --locked`、`./scripts/Package-Windows.ps1 -Tag v0.8.0` 均通过。原生套件覆盖配置写入失败及重试、既有 IME 状态、PNG/JPEG 和剪贴板格式等相关路径。
- **实际输出。** 交错组合的 `output/kiki_20261111_145613.png` 由 System.Drawing 独立解码，大小 1125×477，四角 Alpha 均为 255。抽检一列有 11 个不透明蓝色箭头像素。查看图像确认箭头和中文标注均存在，且工具条、调整点和文字边框未进入成图。深色全关的 500×452 选区实测生成贴图。
- **缺陷复测。** 初次浅色验收发现「保存（Ctrl+S）」悬停提示折行。调整提示宽度和锚点后重新构建并运行完整测试，最终候选在深色靠边场景显示完整单行。原始与复测证据为 `07-light-save-tooltip-before.jpg` 和 `11-dark-edge-tooltip.jpg`。
- **交付核对。** 在带中文和空格的目录解压，核对文件数、包内操作说明、EXE 版本、普通构建与包内 EXE 哈希及 ZIP 校验文件。GUI、成图与日志存放于 Git 忽略的 `artifacts/validation/f07-v0.8.0/`。证据来自隔离设置夹具，屏幕截图中的任务栏未纳入公开资料。
- **性能。** 本阶段主工具条布局使用定长存储，复用现有原生菜单、配置写入及图像输出机制。窄屏参数文字格式随画布释放。本阶段未增加性能采样。
