# P3 原生选区与工具条骨架

日期：2026-11-06。状态：进行中。本轮开始实现后续界面，不重复 P1/P2 已通过的捕获压力测试。

## 已实现

- 默认捕获后进入真实 Win32 全屏冻结画布，使用 Direct2D/DirectWrite 绘制，不再显示旧的 P1 文本诊断窗口。
- 单屏、反向框选、移动选区、八个调整点、物理像素尺寸标签、Esc 取消拖动恢复原状态、F 当前鼠标屏幕全屏选区。
- 捕获时枚举可见顶层窗口，尽量用 DWM 扩展边界排除阴影；过滤最小化和 cloaked 窗口。鼠标悬停高亮，单击选窗的代码已接入，完整实机矩阵仍待验收。
- 按批准顺序绘制 11 个控件：选择 / 矩形、箭头、画笔、文字 / 撤销、重做 / 贴图、保存、复制、取消。圆角面板、细边框、柔和阴影、蓝色强调与复制按钮、线性图标均为真实绘制。
- 当前选择和取消可用，其他控件明确禁用，等待 P4/P5 接入。不是完整编辑器，不将灰色控件当作功能完成。
- 工具条优先选区下方，不足则上方，再不足在一块实际显示器内收纳。横向命中区域与绘制使用同一份布局，Tab 在当前可用控件间移动焦点。
- UI 缩放与底图像素分离，底图仍按物理像素 1:1 绘制。冻结底图在会话中保留，调整选区不会丢弃底图。
- 默认读取系统 UI 背景颜色，接收主题/设置更改通知；可用 --theme=light 或 --theme=dark 手动选择本阶段主题。设置页及配置持久化仍为 P6 工作。

新增直接依赖 windows-numerics = 0.2.0，用于 Direct2D 线段点坐标。它原本已是 windows-rs 的锁定传递依赖，未增加新的下载包或应用运行时，许可 MIT/Apache-2.0。另增加 windows-rs UI_ViewManagement feature 读取公开主题 API。系统字体不随应用打包。

截图命名为 p3-dark-reverse-*、p3-dark-handle-tl/t/tr/r/br/b/bl/l-*、p3-dark-keyboard-cancel-focus-*。八点结果按上表顺序累计调整，不是八次从相同矩形开始。

发现与修正：

- 首次窗口吸附候选异常覆盖整屏。显式开发探针记录窗口类别、扩展样式和物理边界（不记录标题/输入文本/像素），证实电脑操作工具的 CodexComputerUseCursorOverlay 是整屏 WS_EX_TRANSPARENT 窗口；现在过滤这类输入透明辅助层，保留普通可见顶层窗口。
- 深色选中工具的蓝图标在蓝底上对比偏低，已改为浅色图标。禁用按钮仍按阶段状态禁用，没有将其标为功能完成。
- 仅 diagnostics 支持 --trace-window-targets <文件路径>，每次枚举覆盖同一文件；用于复查实际窗口筛选，不随默认应用编译。原始记录在 artifacts/window-targets.txt 和 artifacts/window-targets-filtered.txt（记录的是筛选前快照）。
- 两项修正均已编译，但工具激活 Zed 时返回 user input was detected / window is minimized；随后用户物理 Escape 停止电脑操作。已停止界面输入，修正后的窗口吸附和深色工具图标尚未完成界面复验。

新增逻辑回归覆盖八点保留对边、穿越对边后归一化、窗口单击裁剪、框选/移动取消恢复、屏幕边缘 1×1 选区重新放大。它们验证纯逻辑，不冒充实机极小选区、拖动中 Esc 或多屏结果。12 项 all-features 测试通过，默认及 all-features all-targets 严格 Clippy 通过。最新默认 Release 使用独立 target/p3-validation 构建成功，EXE 366,080 字节，避免覆盖仍在运行的诊断 EXE。

## 窗口吸附复验与边缘布局修正

同一台 Windows 11、1920×1080、125%、SDR，diagnostics Release 的 --accessible-capture 模式：

- 已实际查看四张批准设计图并对照 01/02。悬停记事本准确显示 1426×733；单击后出现同尺寸的八点选框和深色工具条。原始窗口快照的 DWM 边界为 (247,240)–(1673,973)，尺寸一致；这不是被遮挡/最小化窗口隐藏内容的捕获测试。
- 深色选择图标浅色线条在选中底色上清晰，透明辅助层筛选已通过上述实际窗口复验。证据 p3-final-window-hover-*、p3-final-window-selected-dark-*。
- 从屏幕右下角附近拖动极小选区，工具条可收纳于屏内；发现尺寸标签被边界裁掉，首次修正后又与上方工具条重叠。原问题证据 p3-final-edge-label-before-*。最新修正保持标签完整尺寸，先约束在一块屏幕内，再避开工具条；对应逻辑回归通过，最新修正的实机截图尚缺。
- Tab 依次焦点选择、取消，随后 Return 关闭截图；此前未充分确认的 Return 路径现已通过。Enter 复制仍未接通，不能混为一项功能。

代码补全：标签/提示的屏内布局、标签与工具条避让、极小选区按距离选择最近调整点、移动及各方向缩放光标、可用按钮按下态、窗口候选裁剪到冻结图像范围，以及 F 全屏时释放活动捕获。选择工具不显示参数条，标注及输出控件继续明确禁用。

验证：新增边缘标签完整尺寸、与上方工具条不相交，以及极小选区最近调整点的回归。14 项 all-features 测试、默认及 all-features all-targets 严格 Clippy、fmt、默认 Release 构建通过。独立 target/p3-validation 下默认 EXE 368,640 字节。

实机限制：通过工具启动 SystemSettings.exe 后没有得到可操作设置窗口，因此没有修改系统缩放/主题，也没有把 125% 当成 150%/200%。最新版浅色实例已启动，但后续界面检查被用户物理 Escape 中止，已停止输入；按下态、缩放光标、最新标签布局及拖动中 Esc 尚未实测通过。
