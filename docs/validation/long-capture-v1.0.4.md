# v1.0.4 长截图远程显示验收

2026-11-13。用户确认 v1.0.3 经 UU 远程点击长截图时出现整屏画面和滚轮操作异常，同机使用本地键鼠未触发。v1.0.3 会把整个采集遮罩设为屏幕捕获排除窗口。Windows 捕获可因此看不到控制区。UU 客户端具体捕获方式待实测确认。 [Windows API 说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)

v1.0.4 将预览优先布置在选区外，右侧放不下时尝试左侧和上下方。原选区大小和位置保持固定。窗口区域裁剪使遮罩和预览处于采集像素之外。选区和预览不可避免地重叠时，例如实际框选整屏，仍用 Windows 捕获排除防止界面进入成图。此时采用该规则的远程客户端仍可能看不到控制区。

- 在 1920 × 1080、125%、60 Hz SDR 的 Windows 桌面执行 Release 原生测试。点击真实工具条入口后，Windows Graphics Capture 捕获到“完成”按钮。初始选区像素与无覆盖的源窗口逐像素一致。
- 合成滚轮输入使预览由 286 px 增至 325 px。单次测得输入至预览更新 42.6 ms。保存的 509 × 325 px PNG 解码后与拼接底图一致，首帧与原窗口选区一致。
- 全特性测试串行 82 项通过，6 项需单独运行。上述 Release 原生用例已单独通过，Clippy 及格式检查通过。UU 远程客户端和实体双屏待复测。内置浏览器滚动漏段另见 [v1.0.3 验收记录](long-capture-v1.0.3.md)。
