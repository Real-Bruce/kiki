## 实现与环境

- 「设置 → 截图 → 图像输出」新增 PNG/JPEG 下拉选项及对应的圆角示意。旧配置缺少格式字段时默认 PNG，选择后由现有后台写入器保存。
- 截图和贴图复用 Windows 原生另存为。对话框预选默认格式，临时切换时由系统更新文件名后缀。保存前核对确认路径的扩展名与当前类型，通过后将格式随输出任务交给后台。系统同名确认后的目标路径直接用于原子替换。
- PNG 保留透明像素。JPEG 按直通 Alpha 合成到白底，以最多 1 MiB 的 BGR 扫描行缓冲分批写入，并显式设置 WIC `ImageQuality=0.90`。为调用 `IPropertyBag2::Write` 的 `VT_R4` 绑定启用既有 windows-rs 的 Ole 特性。正式 EXE 比 v0.6.1 增加 4608 字节。 [Windows 默认扩展名](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifiledialog-setdefaultextension) · [WIC 编码属性](https://learn.microsoft.com/en-us/windows/win32/wic/-wic-creating-encoder)
- 保存对话框取消时保留文字草稿。确认后使用带草稿的编辑快照成图，写入失败可回到原草稿继续编辑。剪贴板仍提供 PNG、DIBV5 和兼容位图。
- Windows 11 专业版 build 26300，i5-12400（12 逻辑处理器），约 32 GiB RAM，Intel UHD 730 驱动 32.0.101.7088，单屏 1920×1080、60 Hz、125%。Rust 1.88.0/MSVC x64。实机交互使用隔离配置的 Release diagnostics。

## 编码采样

同机 Release 优化下调用与候选包同源的 WIC 编码器。输入是已合成的圆角图像，含中文、箭头及透明间隙。每种格式和尺寸各采 30 次，计时从开始编码到文件流释放，涵盖文件写入。保留全部波动样本。峰值工作集为采样进程累计值，文件写入采样的句柄数在各组首尾均为 150。

| 尺寸 | 格式 | P50 / P95 / 最大 | 峰值工作集 | 采样最大 private bytes |
| --- | --- | --- | --- | --- |
| 640×360 | PNG | 5.910 / 7.695 / 8.558 ms | 30.80 MiB | 14.16 MiB |
| 640×360 | JPEG | 4.035 / 4.873 / 5.755 ms | 30.80 MiB | 14.23 MiB |

| 1920×1080 | JPEG | 11.554 / 70.524 / 109.263 ms | 52.37 MiB | 28.69 MiB |
