## 环境与实现

- 2026-11-11，Windows 11 x64 build 26300.9974，Intel Core i5-12400，Rust 1.88.0/MSVC x64。合成采样和像素夹具使用独立 Release 测试程序，图像和坐标为合成数据。
- 每个马赛克保存覆盖矩形及颗粒边长。颗粒网格从矩形左上角起算，单元颜色按冻结底图有效像素求均值。重叠处较晚创建的马赛克覆盖较早的效果，各自从同一底图取样。透明间隙保持透明，缩放选区不会重算已有可见颗粒的颜色。
- 预览保留一张效果位图，只在马赛克对象改变时重算。成图在后台应用同一像素逻辑，再绘制普通标注并裁圆角。复制、保存和贴图共用成图流程。
