# v1.0.11 贴图菜单与悬停工具条验证

2026-11-17，Windows 11 x64（10.0.26300.0），Intel Core i5-12400，单屏 1920 × 1080，125%（120 DPI）。Rust 1.88.0，MSVC x64。浅深界面验证使用 Release diagnostics 与隔离配置，ZIP 烟雾测试使用正式 Release 解压副本。

## 真实界面与输出

- 对照 04 贴图稿、S09 矢量图标方向及当前界面。用两张 640 × 360 合成测试图验证真实贴图窗口。浅深两种主题分别查看贴图及托盘原生右键菜单：圆角、暖灰表面、分隔线与松绿选中样式一致，贴图快捷键靠右且与标签保持间距。
- 贴图右上角复制、保存、关闭均为线性矢量图标，采用同一描边与等宽热区，光标移到保存按钮可见对应高亮。双主题截图：[浅色工具条](../../screenshots/pinned/toolbar-light.png)、[深色工具条](../../screenshots/pinned/toolbar-dark.png)、[浅色菜单](../../screenshots/pinned/menu-light.png)、[深色菜单](../../screenshots/pinned/menu-dark.png)。
- 两种主题均实际右键打开菜单，Esc 收起且贴图保留；滚轮放大至显示 704 × 397，点击菜单「恢复原始比例」回到 640 × 360；点击右上角关闭仅关闭操作的那一张。
- 放大后点击右上角保存，从原生对话框写出 PNG；两种主题的 PNG 均为 640 × 360，SHA-256 均为 `923e22f09a8d42d09eddb7ef9afd7516611d0ee1b15909c2a8822240ac0f7987`。单独解码及查看 PNG，标注、透明区保留，图像不含悬停工具条、提示或菜单。透明区 (450,300) 的 alpha 为 0；工具条覆盖区域的 (550,35) 保留原图浅灰 `#F8F8F8` 且 alpha 为 255。
- 正式 ZIP 检查 17 个条目、版本、许可及 SHA-256，启动解压的 EXE 后实际框选色板并按 Ctrl+P，贴图为 430 × 190；复验悬停、右键、滚轮缩放、菜单恢复以及点击关闭。
