# F07 人工反馈修订 · v0.8.1

2026-11-11。基于 [F07 v0.8.0](F07-v0.8.0.md) 修订。范围包括移除选择按钮、设置开关的同序图标和实时预览。构建与测试对应实现提交 `c9fc767`，根据用户要求本地放行。

## 布局草图

```text
工具显示
[□ 矩形  开关] [↗ 箭头  开关] [画笔图标  画笔  开关] [T 文字  开关]

工具条预览
[□  ↗  画笔图标  T │ 撤销  重做 │ 贴图  保存  复制 │ 取消]
```

窄设置窗口将开关按行折为两列，预览等比缩放并显示全部启用工具。实时预览与截图共用布局和图标，预览内的操作按钮仅供查看。

## 验收结果

环境为 Windows 11 x64 build 26300，1920×1080 单屏、125% 缩放、60 Hz、SDR。GUI 使用 v0.8.1 Release diagnostics 及独立配置。
