# 截图工具条与标注优化验证

## 实施与验证

- 工具条按批准稿和逻辑尺寸调整为 48 DIP 高，普通按钮命中区为 36×36 DIP，图标为 18 DIP 级别。使用独立按钮、组间留白和细边框，移除了底部偏移阴影。
- 箭头保持鼠标按下点，实心尖端跟随拖动。笔画使用圆头和圆连接的连续路径，保留鼠标释放位置。绘制时无对象线框，选择时箭头显示端点、画笔沿轨迹高亮。
- 使用系统 Msftedit.dll 的无窗口文本服务接收编辑消息，在现有 Direct2D 画布上通过 GDI 互操作透明绘制。DirectWrite 测量编辑框并渲染提交后的文字。windows-core 是锁文件中已有的传递依赖，本次直接引用以实现系统 COM 宿主，没有新增第三方包版本。普通 EXE 比 P8 基线增加 37,888 字节。
- 用户手动确认输入时底图可见。用户提交的实际成图包含多行中英文、实心箭头、不同宽度的画笔和矩形，图中没有箭头/画笔选择框。证据保存于忽略目录 `artifacts/visual/ui-polish/manual-output.png`。
- 运行 Release 诊断成图并检查 `fixture-annotated.png`，可见旋转后的两行中文、实心箭头和笔画，旋转文字进入实际 PNG。探针另生成真实桌面裁剪 `desktop-annotated.png`，保留于同一忽略目录。
- 在 Windows 桌面会话运行默认和全特性测试各 43 项。覆盖文字尺寸增减、文本内撤销、多行、旋转命中及撤销重做、成图裁剪、原生窗口透明绘制调用和输出失败恢复。早期沙箱内测试受系统权限限制，最终桌面会话两组全数通过。
- rustfmt、默认及全特性严格 Clippy、两种 Release 构建、`git diff --check` 通过。
- 电脑操作工具获取窗口状态时两次报告 `foreground window did not report a process id`。最终深浅工具条、边缘布局、100%/150%/200% 的视觉对照未完成。鼠标旋转手柄及光标、拼音候选交互仍待完整实机验证。多屏、混合 DPI 和 HDR 继承 P7/P8 的验收限制。
