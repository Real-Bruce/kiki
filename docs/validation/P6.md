# P6 第一批：配置与热键基础

日期：2026-11-06。状态：P6 已开始，当前完成基础模块验证，六页设置界面及运行时接入待继续。P5 单屏 SDR 验收完成、P3 暂缓的状态保留。

## 已实现

- core/config.rs：版本 1 配置模型，主题、截图热键、操作提示、首次提示状态、工具默认颜色/线宽/字号、最近保存目录。64 KiB 输入上限、数值与热键校验；中文目录和等号可往返，非法或重复字段不会部分应用。
- windows/config_store.rs：LocalAppData/kiki/settings.ini 路径、文件加载、同目录临时文件写入/同步/原子替换，损坏配置保存前保留备份，最多三份且不覆盖已有备份；更高版本或不可读配置保留原件并禁止覆盖。
- 配置写入工作者：一份待写快照及一份结果，180 ms 合并连续更改，按 revision 返回保存结果；退出时写完最后一份。UI 接入后必须仅在最新 revision 成功后显示自动保存成功。
- windows/hotkey.rs：先注册候选热键，再释放旧注册；候选冲突保留原注册，重复设置当前组合不重注册。提供原生热键输入控件双向转换，限定 Ctrl/Alt 加字母、数字或功能键。

上述模块当前用 cfg(test) 启用，作为可验证的 P6 基础检查点，普通程序尚未接入这些模块。没有增加 Cargo 依赖，没有启用实际开机启动，也没有把测试配置写入用户 LocalAppData。

## 实际验证

- 全套 all-features 38 项测试通过，新增 6 项：配置往返、无效配置、实际已知目录路径、损坏/未来版本保护、锁定目标与后台最后 revision 保存、原生系统热键冲突/替换及真实热键控件往返。
- 保存测试实际锁定文件，确认原字节不变、临时文件清理；连续提交 100 份配置并确认最新 revision 完成，再提交第 101 份后立即退出，确认最后一份仍被持久化。
- 系统热键测试在测试自有窗口短暂注册两个可用的 Ctrl+Alt+F19–F24 组合，制造实际冲突，确认旧组合继续被占用、候选解锁后替换成功、旧组合随后可被重新注册。测试结束释放全部注册与窗口。
- fmt、默认及 all-features all-targets 严格 Clippy、默认 Release 构建通过。P6 本轮未运行设置窗口视觉验收，不将新基础模块标为产品端设置已可用。
