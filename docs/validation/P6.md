# P6 设置、主题与运行体验

日期：2026-11-07。状态：功能实现完成，当前 Windows 单屏 SDR、1920×1080 / 125% 缩放验收通过；150%/200%、混合 DPI 和真实登录自启验证保留给 P7 的环境矩阵。P3 继续按用户要求暂缓，P2/P4 原实机遗留保留。

## 实现范围

- `preferences.rs` 把配置、后台写入工作者和系统热键事务接入正常程序。配置位于当前用户 LocalAppData/kiki/settings.ini，无新 crate；Registry 与 Accessibility 是现有 windows crate 的新增功能开关。
- 六页设置：通用、快捷键、截图、贴图、外观、关于。左侧蓝色导航标记、右侧分组卡片、标准 Windows 标题栏；Direct2D/DirectWrite 绘制卡片文字，原生 BUTTON / HOTKEY 控件提供键盘交互。小窗口内容可滚动，页眉页脚固定，越过内容视口的控件隐藏。
- 热键更改先注册候选，再释放旧组合；失败保留当前配置与注册。启动时冲突仍保留托盘入口，冲突解除后可用相同配置重新注册。原生热键框聚焦时不会误启动截图，释放组合键后恢复有效显示。可恢复 Ctrl+Alt+A 默认值。
- 主题支持系统、浅色、深色，通知设置、截图工具条/参数条、原生文字输入、贴图控件、托盘和贴图菜单、帮助与许可窗口。原生菜单保留系统键盘行为，并用 MSAAMENUINFO 暴露绘制菜单项的名称。
- 提示开关控制非关键工具提示、截图底部说明和贴图缩放提示；输出进度和错误仍显示。新截图读取默认颜色、线宽、字号，已有标注不被修改。保存对话框固定 PNG，并持久化最近目录。
- 托盘补齐当前屏幕截图、设置和关闭所有贴图；首用时请求系统提示，成功请求后记录 first_tip_seen。支持 `--settings`、`--capture`、`--capture-screen`，已有实例接收相应请求。
- 开机启动初始关闭，仅用户点击时写 HKCU Run 的 kiki 值。命令引用当前 EXE 的完整路径；旧路径可显式修复或关闭，加载设置不会自动启用。
- 关于页有版本、当前热键、配置目录、帮助、第三方许可。许可原文从 Cargo.lock 对应 crate 包中汇总并嵌入 EXE，可离线阅读。长文本先创建空 EDIT 再加载，避免窗口创建参数长度限制。
- 写入按最新 revision 回执显示 Ready / Saving / Saved / Failed，失败有重试入口；损坏备份、更高版本保护、原子替换沿用基础实现。退出先结束消息泵，再关闭窗口、回收工作者并注销热键，最后销毁隐藏宿主。
