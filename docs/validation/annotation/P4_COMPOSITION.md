# P4 标注成图链路验证

日期：2026-11-06。P3 继续按用户要求暂缓。本轮推进 P4 的成图语义，并为 P5 输出建立基础；用户输出入口尚未接通。

## 实现与边界

- 提取 annotation_render：截图预览与干净成图共用矩形、箭头、笔画、文字的绘制代码和 DirectWrite 布局，统一物理坐标与灰阶文字抗锯齿；绘制结束恢复目标原有文字抗锯齿状态。
- 新增 WIC/Direct2D 软件成图模块：独立裁剪底图，叠加标注并读回直通 BGRA；检查步长、缓冲长度和坐标尺寸，转换预乘 alpha，保留透明区域。
- 成图函数只接收不可变底图与编辑器，不修改编辑内容，不调用工具条、尺寸标签、选区线和对象调整点的绘制路径。
- 当前 composition 仅在 diagnostics/test 构建启用。默认产品只复用新的共享标注绘制模块；复制、保存、贴图按钮继续禁用，尚未声称接通 P5。
- 没有新增 crate、工具链升级或分发运行时。默认 Release 526,336 字节；未进行新一轮性能测量。

## 实际执行

- fmt 检查通过；默认及 all-features all-targets 严格 Clippy 通过。
- all-features 25 项测试通过。新增原生成图回归覆盖负坐标、裁剪不漂移、底图不变、选中状态不进入成图、未覆盖区域像素不变、透明间隙及半透明抗锯齿。
- 全图 640×360，取其中 400×210 区域；独立区域成图与完整成图裁剪逐字节相同（84,000 个像素）。这验证同一软件后端的裁剪语义，不是 GPU 预览截图逐像素比对。
- 默认及 diagnostics Release 构建成功，分别位于 target/p4-output-checkpoint 和 target/p4-output-validation。
- 实际运行 `--annotation-probe artifacts/p4-composition`，退出码 0，输出两个 640×360 PNG，并实际打开检查：
  - fixture-annotated.png：明确的人工构造测试底图，包含负坐标原点与透明间隙，叠加中文两行、矩形、箭头和笔画；不是软件 GUI 截图。
  - desktop-annotated.png：本机 WGC 的真实桌面左上角裁剪，加上诊断脚本指定的标注；不是用户手工编辑结果，也不作为最终交互验收。
- 两张图的文字和几何标注实际可见，未见工具条、选择框或尺寸标签。透明间隙由像素检查确认；查看器中显示为黑色背景不代表输出被填黑。
- 输出位于忽略的 artifacts/p4-composition，不进入 Git。测试素材只存在于开发诊断模块，不成为正常应用 UI 或示例桌面内容。
