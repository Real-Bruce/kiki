# F01 验收报告

2026-11-11，Windows 11 专业版 build 26300，Rust 1.88.0 / MSVC x64。**v0.3.0 候选已实现，待完成环境验收。**

桌面复测使用 Intel Core i5-12400、12 个逻辑处理器、约 31.7 GiB RAM、Intel UHD Graphics 730（驱动 32.0.101.7088）。本次 GUI 画布为单屏 1920 × 1080、125% 缩放、60 Hz。系统另列虚拟显示适配器，未将其计入多屏验收。

用例定义见 [F01 验收计划](../ACCEPTANCE_PLAN.md#f01) 和 [公共回归](../ACCEPTANCE_PLAN.md#common)，视觉依据为 [S01 草图](../design/next/README.md)。本地实现与本报告随同一提交交付。

## 用户验收与文字修正

用户确认线框、箭头、自由画线的直接拖动通过，指出文字拖动及旋转需要反复点击。用户截图留在忽略目录下的 `artifacts/validation/f01-v0.3.0/manual-user.png`，SHA-256 为 `A886F69153E58526082159025287120E8D76F742D84F7463D7451CED4C41E27F`。

修正后，文字草稿显示可直接使用的边框和旋转圆点。圆点起拖时提交草稿，并使用同一鼠标按下事件开始旋转。边框周围按显示缩放留出命中余量。截图窗口从 Win32 鼠标事件读取按下、移动和松手的坐标，避免快速拖动时用已经移动过的光标位置判定起点。输入框内部仍交给原生文字编辑器。

## 自动检查与候选包

- 默认及全特性各 **49 项通过**。严格 Clippy、rustfmt 和 `git diff --check` 通过。早期沙箱运行受热键、注册表和临时文件访问限制，完整测试在正常 Windows 权限下复测。
- 原生输出测试覆盖取消另存、写入失败保护、剪贴板占用后重试与贴图。WIC 测试检查 PNG 尺寸、像素和透明间隙。
