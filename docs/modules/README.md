# 功能模块导航

各模块串联“设计与行为 → 开发入口 → 验证记录 → 真实界面”。当前完成情况只维护在 [PROGRESS.md](../PROGRESS.md)，计划和历史不作为第二份状态表。

| 模块 | 范围 |
| --- | --- |
| [普通截图与工具条](capture.md) | 普通截图默认先冻结桌面，再选择区域、可见窗口或当前屏幕 |
| [标注与参数](annotation.md) | 矩形、箭头、画笔、文字、马赛克和顺序编号共享可编辑对象及有界撤销历史 |
| [取色](color-picker.md) | 从冻结底图或已拼接长图采样颜色 |
| [长截图](long-capture.md) | 在单屏固定区域内手动纵向滚动，匹配并追加新内容，再进入可标注的静态长图编辑 |
| [输出与圆角](output.md) | 复制、文件保存、生成贴图是独立动作，使用相同的干净成图语义 |
| [置顶贴图](pinned.md) | 将已合成图像显示为独立置顶浮窗，可同时保留多张 |
| [设置与运行入口](settings.md) | 通用、快捷键、截图、贴图、外观、关于六页设置，配合托盘入口、系统注册热键、可选开机启动、自动保存与主题切换 |
| [视觉资源](visuals.md) | 统一暖灰、松绿、线性图标和 Win11 圆角 |
| [工程、性能与交付](engineering.md) | Rust 2024 / Rust 1.88.0 / Windows MSVC x64 |
